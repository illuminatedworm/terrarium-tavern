本项目许可是改编后的独立许可，不能标为 `Apache-2.0`，也不构成供用户择一适用的双重许可。该区别符合 [Apache 软件基金会对修改许可的说明](https://www.apache.org/foundation/license-faq.html#mod-license)。[Apache 2.0 原文](https://www.apache.org/licenses/LICENSE-2.0.txt)仅用于对照，不是本项目原创部分的另一项授权。
