# 前端视觉与交互原则

- 暗色、低饱和的“石墨玻璃”桌面阅读风格：中性石墨底、偏暖的纸色文字、象牙色主操作、单一灰蓝强调色（焦点、选中与运行状态）；叙事为主要内容。颜色、字号、圆角、阴影、层级、缓动与材质统一取自 `web/styles/tokens.css`，不另写散落色值或像素档位。
- 配色方案只在 `tokens.css` 的调色板组中定义：需要透明度变体的色相以 `--*-rgb` 通道给出，实色表面与文字直接给值；其余样式用 `rgb(var(--accent-rgb) / α)` 或 `color-mix()` 派生；更换配色只改该组。缓存断点金色、搜索高亮与上下文分类色属于语义色，不随配色变化。中性白/黑的半透明叠加（高光、描边、阴影）可直接书写；第三方品牌按钮与隔离 iframe 的兜底样式例外，须注明原因。
- 字号取 `--fs-*` 阶梯，圆角取 `--radius-*`，挂到 body 的浮层用 `--z-*` 层级；组件内部只排序自身子元素的小 z-index 可直接书写。媒体查询不能读取变量，宽度断点只用 `tokens.css` 注释列出的档位。
- 样式按层组织：`tokens.css`（令牌与材质）→ `base.css`（重置、控件、正文）→ `shell.css`（框架）→ `story.css`（游玩界面）→ `composer.css`（共用对话输入框）→ `overlays.css`（弹窗与浮层）→ `pages.css`（整页视图）→ `settings.css`。同一元件的规则只写在所属层的一处，不在后段追加覆盖。
- 材质分层由 `tokens.css` 的 `--glass-*` 变量定义：画布（墨色底与边缘静态环境光）→ 面板（左侧导航与右侧检查栏为毛玻璃）→ 阅读区（近乎透明，保证正文对比度）→ 浮条（对话输入框悬浮于消息列表之上，正文从其下方滚过）→ 浮层（弹窗、菜单、提示、通知）。新组件选用对应的 `--glass-*` 变量，不自造半透明配方。
- 毛玻璃只用于界面框架与浮层；正文和角色卡 iframe 不放在重度模糊上。玻璃下方不放持续动画，长列表的单项不加 `backdrop-filter`。
- `--surface-*` 保持不透明，供吸顶行与需要遮挡的元素使用；描边 `--border-subtle/control` 为半透明白，不作文字颜色。
- 带 `backdrop-filter` 的面板会成为 fixed 后代的定位容器，浮层必须 Teleport 到 body 或使用 popover API。
- 不支持模糊、系统要求减少透明度，或用户在“阅读排版”关闭“毛玻璃效果”（`<html>` 带 `no-glass`）时，玻璃变量退化为不透明表面并停用全部 `backdrop-filter`；依赖磨砂遮挡滚动内容的吸顶行须在该模式下给出不透明背景。
- 图标统一使用 `components/common/Icon.vue` 的线性图标（24 网格、圆角端点），不再用 Unicode 符号充当图标；制卡与参谋的历史图标名映射到同一套图标；按钮内以图标开头时自动排成带间距的行。纯图标按钮必须有 `aria-label` 与 `title`。
- 左侧为导航轨（品牌、会话/角色卡/制卡、用户角色、阅读排版、设置、关于、折叠）加列表面板；折叠只收起列表面板，导航轨保留。右侧检查栏镜像同一交互：外侧常驻页面轨（参谋、缓存、工具、MVU 变量、场景、会话设置、折叠），面板在轨内侧展开；点击当前页收起面板，点击其他页切换或展开到该页。窄屏两侧均为带导航轨的抽屉，收起后以悬浮按钮重新打开。
- 设置弹窗：标题徽记、搜索与保存状态一行；左侧按模式分组导航，右侧为“模式眉标 + 页面标题”和单列滚动内容，分节标题带延伸细线。整页编辑器（角色卡、用户角色、开局）使用返回按钮、头像标题区、吸顶下划线分页与居中内容列；开局选卡为头像卡片画廊。
- 按钮层级：象牙色 `.primary` 为每个视图唯一主操作；默认按钮为半透明描边；`.quiet`/`.icon-button` 用于工具栏；危险操作用 `.danger`。
- 次级对话面（制卡、参谋）的输入框与游玩输入框共用同一磨砂框。内容分页标签（设置）的选中态为发光下划线，悬停不叠加底色；侧栏导航轨的选中态为外侧发光竖条；视图切换（如对话/后台工作记录）使用分段控件。
- 正文排版服从用户字体、字号、行距和阅读宽度，辅助控件应紧凑。
- 对话输入框高度由程序测量并写入 `--composer-height`：消息列表据此预留底部空间，导航、跳转与重新生成面板据此上移，最新消息不得被输入框遮住。
- 根页面永不滚动；对话、侧栏、编辑页和弹窗内容各自内部滚动。
- 弹窗按用途使用固定高度档位，受视口上限约束；内容或标签切换不改变外框高度。
- 模态面板须有背景交互隔离、焦点约束、可见关闭入口和键盘焦点。
- 跳到最新是条件显示的悬浮箭头，位于右侧导航列（消息跳转胶囊下方、输入框上沿），不压正文、不占输入区布局行。正文栏左右留白对称；右侧检查栏最多占窗口宽度的 35%，优先保证正文栏。
- MVU 原始变量面板默认展开（有卡片状态面板时位于其下方），深层节点可折叠，侧栏宽度与折叠偏好由用户掌握。
- 角色 HTML/MVU 在隔离 iframe 中显示，保留作者样式，不强制覆盖卡片主题。
- 数字和状态名称必须对应真实后台口径；token 实际量与本地估算不可混称。
- 保留清晰的禁用、加载、错误和重试反馈，背景维护失败不能只藏在日志里。
- 布局验收视口见[长期使用与发行](RELEASE.md#打包与发行前验收)。
- 布局、组件、导航可以为新功能调整；这些原则不要求保持历史控件位置。
