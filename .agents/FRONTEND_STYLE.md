# 前端视觉与交互原则

界面采用暗色、低饱和的“石墨玻璃”桌面阅读风格：中性石墨底、偏暖的纸色文字、象牙色主操作，以及单一的灰蓝强调色（用于焦点、选中与运行状态）。叙事是主要内容，辅助控件保持紧凑。

以上为整体基调与氛围，而非逐项适用的唯一标准。具体元素的颜色、对比度、强调方式与密度取决于所处情景、承担的功能和用户感受：警告与阻断须足够醒目，长时间阅读的区域宜柔和稳定，状态读数应一眼可辨。基调服务于整体协调，不以牺牲可读性与可用性为代价。

本文件约束视觉令牌、样式组织、材质、布局与交互反馈。布局、组件和导航可以为新功能调整，这些原则不要求保持历史控件位置；布局验收视口见 [长期使用与发行](RELEASE.md#打包与发行前验收)。

## 设计令牌

颜色、字号、圆角、阴影、层级、缓动与材质统一取自 `web/styles/tokens.css`，不另写散落的色值或像素档位。

- **配色**：配色方案只在 `tokens.css` 的调色板组中定义。需要透明度变体的色相以 `--*-rgb` 通道给出，实色表面与文字直接给值；其余样式用 `rgb(var(--accent-rgb) / α)` 或 `color-mix()` 派生。更换配色只改该组。
- **语义色**：缓存断点金色、搜索高亮与上下文分类色表达固定含义，不随配色变化。
- **允许直接书写的例外**：中性白／黑的半透明叠加（高光、描边、阴影）可直接书写；第三方品牌按钮与隔离 iframe 的兜底样式也属例外，但须注明原因。
- **尺寸与层级**：字号取 `--fs-*` 阶梯，圆角取 `--radius-*`，挂到 body 的浮层用 `--z-*` 层级；组件内部只排序自身子元素的小 z-index 可直接书写。
- **断点**：媒体查询不能读取变量，宽度断点只用 `tokens.css` 注释中列出的档位。

## 样式分层

样式文件按以下顺序组织，后一层建立在前一层之上：

1. `tokens.css`：令牌与材质
2. `base.css`：重置、控件、正文
3. `shell.css`：应用框架
4. `story.css`：游玩界面
5. `composer.css`：共用对话输入框
6. `overlays.css`：弹窗与浮层
7. `pages.css`：整页视图
8. `settings.css`：设置

同一元件的规则只写在所属层的一处，不在后段追加覆盖。

## 材质与毛玻璃

材质分层由 `tokens.css` 的 `--glass-*` 变量定义，自下而上依次为：

- **画布**：墨色底与边缘静态环境光。
- **面板**：左侧导航与右侧检查栏，使用毛玻璃。
- **阅读区**：近乎透明，保证正文对比度。
- **浮条**：对话输入框悬浮于消息列表之上，正文从其下方滚过。
- **浮层**：弹窗、菜单、提示与通知。

新组件选用对应层的 `--glass-*` 变量，不自造半透明配方。`--surface-*` 保持不透明，供吸顶行与需要遮挡的元素使用；描边 `--border-subtle/control` 为半透明白，不作文字颜色。

毛玻璃只用于界面框架与浮层，正文和角色卡 iframe 不放在重度模糊上。玻璃下方不放持续动画，长列表的单项不加 `backdrop-filter`。

带 `backdrop-filter` 的面板会成为 fixed 后代的定位容器，因此浮层必须 Teleport 到 body 或使用 popover API。

**退化模式**：浏览器不支持模糊、系统要求减少透明度，或用户在“阅读排版”中关闭“毛玻璃效果”（`<html>` 带 `no-glass`）时，玻璃变量退化为不透明表面并停用全部 `backdrop-filter`。依赖磨砂遮挡滚动内容的吸顶行须在该模式下给出不透明背景。

## 图标与控件

图标统一使用 `components/common/Icon.vue` 的线性图标（24 网格、圆角端点），不用 Unicode 符号充当图标；制卡与参谋的历史图标名映射到同一套图标。按钮以图标开头时自动排成带间距的行。纯图标按钮必须有 `aria-label` 与 `title`。

按钮分为四个层级：

- `.primary`：象牙色，每个视图唯一的主操作。
- 默认按钮：半透明描边。
- `.quiet`／`.icon-button`：用于工具栏。
- `.danger`：危险操作。

选中态按位置区分：内容分页标签（如设置）为发光下划线，悬停不叠加底色；侧栏导航轨为外侧发光竖条；视图切换（如对话／后台工作记录）使用分段控件。

即时生效的持久开关用 `input[type=checkbox].switch`（带 `role="switch"`）；长文本草稿的保存栏只在有未保存修改时出现。

## 应用框架

### 左侧导航

左侧由导航轨与列表面板组成。导航轨依次包含品牌、会话／角色卡／世界书／制卡、用户角色、阅读排版、设置、关于与折叠按钮。折叠只收起列表面板，导航轨保留。

### 右侧检查栏

右侧检查栏镜像同一交互：外侧常驻页面轨（参谋、缓存、工具、原著（Full Agent）、MVU 变量、场景、会话设置、折叠），面板在轨内侧展开。点击当前页收起面板，点击其他页则切换或展开到该页。检查栏最多占窗口宽度的 35%，优先保证正文栏。

各页刻意使用不同版式，让用户第一眼即可分辨：

| 页面     | 版式                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 工具     | 分组开关清单                                                                           |
| 原著     | 书封式文件卡与调查任务卡                                                               |
| 场景     | 带标题栏的分块笔记本                                                                   |
| 会话设置 | 编号分节表单                                                                           |
| 缓存     | 接入规格铭牌，加时效、断点与状态读数；各渠道共用同一骨架，不可用的区只留一行原因与入口 |
| MVU 变量 | 卡片状态面板，加内嵌的原始变量键值树                                                   |

各页版式写在各自组件或所属样式层，不抽共用页面组件；共用的只有控件（`input.switch`、`FieldHelp`、`Icon`）。页头由图标、标题与一行状态摘要组成。警告与阻断常显；一行能说清的提示写成小字，原理说明收进 `FieldHelp`。

MVU 原始变量面板默认展开（有卡片状态面板时位于其下方），深层节点可折叠；侧栏宽度与折叠偏好由用户掌握。

### 设置弹窗与整页编辑器

设置弹窗的首行放标题徽记、搜索与保存状态；左侧为按模式分组的导航，右侧为“模式眉标 + 页面标题”和单列滚动内容，分节标题带延伸细线。

整页编辑器（角色卡、用户角色、开局）使用返回按钮、头像标题区、吸顶下划线分页与居中内容列；开局选卡为头像卡片画廊。

## 阅读区与对话输入框

正文排版服从用户设置的字体、字号、行距和阅读宽度，正文栏左右留白对称。

对话输入框高度由程序测量并写入 `--composer-height`：消息列表据此预留底部空间，重新生成面板据此上移，最新消息不得被输入框遮住。消息跳转胶囊和对话刻度栏按阅读区定位，场外输入框开合时保持在原位。次级对话面（制卡、参谋）的输入框与游玩输入框共用同一磨砂框。

“跳到最新”是条件显示的悬浮箭头，位于右侧导航列，通常贴在输入框上沿。宽而矮的窗口中，箭头靠近右侧导航列底部，给消息跳转胶囊留出空间。

角色 HTML／MVU 在隔离 iframe 中显示，保留作者样式，不强制覆盖卡片主题。

## 滚动、弹窗与焦点

- 根页面永不滚动；对话、侧栏、编辑页和弹窗内容各自内部滚动。
- 弹窗按用途使用固定高度档位，受视口上限约束；切换内容或标签不改变外框高度。
- 模态面板须有背景交互隔离、焦点约束、可见的关闭入口和键盘焦点。

## 窄屏与 Android

### 抽屉

窄屏时左右两侧均为带导航轨的抽屉，收起后以悬浮按钮重新打开。右侧检查栏在 1200px 及以下宽度即转为抽屉，避免正文栏被挤窄后输入框遮住阅读区。

### 手机宽度

手机宽度（620px 及以下）以正文宽度优先：

- 游玩页顶栏压成一行（标题、视图切换、“更多工具”菜单），工具与对话搜索收进菜单。
- 正文右侧只留历史轨宽度。消息跳转胶囊仅在滚动时浮现于正文边缘，静止约 2 秒后隐去；跳到最新箭头同样可浮于正文末行之上。
- 右侧抽屉展开时占满屏宽，不留遮罩条，从页面轨收起；页面轨与内边距收窄，卡片状态栏贴边显示。

### Android 宿主

Android 宿主（`<html>` 带 `android-host`，由 `window.TavernAndroid` 判断；桌面窄窗口不带）在手机布局上进一步让出正文：

- 离开最新位置时输入框滑出阅读区；回到底部、展开重写面板或输入框持有焦点时回来。跳到最新箭头留在底边。
- 消息跳转胶囊更小更淡、无模糊，静止约 1.2 秒后隐去。
- 历史轨与跳到最新箭头平时半透明，触摸或预览时恢复。

## 数据口径与反馈

界面上的数字和状态名称必须对应真实后台口径；token 实际量与本地估算不可混称。保留清晰的禁用、加载、错误和重试反馈，背景维护失败不能只藏在日志里。
