# 模型输入的文本完整性原则

适用于 Writer、Tracker、Full Agent、Card Editor、MVU 分析及其工具续答。

Advisor（参谋 agent）同样遵守完整文本规则。其独立咨询窗口允许按完整交流退出旧咨询，以界面可查看的咨询摘要或用户选择的独立云端 compact 承接；当前会话的完整咨询与工具原文可回查，用户清空会话时一并删除。此机制不授权摘要替代当前选中的剧情、角色资料、世界书或工具结果，不修改主故事 handoff、note、plot 或分类记忆。

用户明确选择官方渠道 Half Agent 或 Full Agent 的云端 compact 时，允许服务端以加密压缩状态承接此前工作上下文。本地剧情、冻结世界书及工具原文仍完整保存；上下文方式切换、来源变更或状态失效后，从完整可回放来源按目标上下文长度判断是否需要转换，原文可以直接承载时不发整理请求。转换只按完整用户／AI 交流分批，同轮锚定资料、用户输入、工具调用／结果与最终 AI 回复不可拆开；为保留完整交流允许超出窗口上限，不得截断单个内容块。Half Agent 的 compact 只代替 Writer 窗口裁剪，不代替 Tracker 记忆；切回本地滚动窗口须补齐必要的记忆来源覆盖。此例外不授权本地静默摘要、遗漏历史或改写 notes。

- 检索可以决定**哪些**条目相关，窗口可以按完整交流边界退出旧历史；一旦文本块被选中，发送给模型的必须是展开宏、完成安全投影后的**完整内容**。世界书条目、角色字段、用户输入、提示词配方块、历史原文、工具结果和辅助资料均如此。
- 不因块长、字符数、token 估算、上下文压力或模型服务上限，截掉前后部分、按页回读、拆散后只发送部分、静默省略已选块，或使用其他内容替代原文。
- 长度预算可用于提示、统计和决定是否换出**完整的旧交流**；不得用于修改单个文本块或丢弃已选中的设定与资料。超量时给用户简短提示，仍提交完整请求。服务商拒绝时如实报告错误，不掩饰为成功。
- 搜索摘要属于定位信息，必须明确标为摘要；读取原文的工具一次返回全文。UI 为人浏览日志而分页，不改变模型收到的内容。
- 安全投影隐藏程序内部 ID、指纹和账本；该规则不允许以文本完整性为由泄露内部字段。删除用户源文本中的实际语义内容也不是投影。
- 回归测试应检查最终发给模型的消息，包含超长单条目、超长工具结果及超长历史，并验证尾部仍在请求中。
