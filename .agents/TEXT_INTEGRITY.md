# 模型输入的文本完整性原则

本原则约束 Writer、Tracker、Full Agent、Card Editor、Advisor、MVU 分析及其工具续答处理的**角色卡和项目内部数据**。“读取原文一次返回全文”不是对所有信息来源的统一要求。

## 适用范围

- **内部数据**：角色卡字段、世界书条目、用户角色、已保存剧情与对话、记忆、变量、handoff、笔记、提示词配方、项目内置指引，以及选中的内部历史与工具记录。选择必要条目或字段后，读取其完整内容；不为应对模型上下文压力对该内容分页、截断或改用摘要。
- **外部资料**：网络搜索结果、网页提取正文、外部文本文件、DOCX/XLSX 等文档，不受“一次返回全文”的要求约束。这些来源可能非常大，应按独立的有界读取协议处理，不因本原则强制全文下载、解析或送入模型。
- 工具记录保存的是**本次实际返回的结果**。保存、回放一个外部资料片段不意味着取得了外部原文全文，也不将其余未读取部分变成必须加载的内部数据。

## 内部数据的完整读取与发送

- 检索可以决定**哪些**内部条目相关，窗口可以按完整交流边界退出旧历史；一旦内部文本块被选中，发送给模型的必须是展开宏、完成安全投影后的**完整内容**。
- 不因块长、字符数、token 估算、上下文压力或模型服务上限，截掉已选内部数据的前后部分、按页回读、拆散后只发送部分、静默省略，或使用摘要替代原文。
- 长度预算可用于提示、统计和决定是否换出**完整的旧交流**；不得用于修改单个已选内部文本块或丢弃已选设定。超量时给用户简短提示，仍提交完整请求。服务商拒绝时如实报告错误，不掩饰为成功。
- 内部搜索摘要属于定位信息，必须明确标为摘要；随后读取选中字段、条目或历史记录时一次返回全文。UI 为人浏览日志而分页，不改变模型收到的内容。
- 安全投影隐藏程序内部 ID、指纹和账本；该规则不允许以文本完整性为由泄露内部字段。删除用户源文本中的实际语义内容也不是投影。

## 外部网络与文件资料

- 按用途限制搜索结果数量、下载字节、解析／解压资源、处理时间及返回正文大小；下载上限不能代替模型输入量上限。可以明确选择摘要、片段、分页或超限拒绝，不要求补读不相关部分以拼成全文。
- 如实标明来源、返回的是摘要／片段／转换文本还是全文、已知截断状态；可续读时提供定位或续读参数，不可续读或服务没有披露完整性时说明限制。不得把未知完整性或被截断的结果称为全文。
- 在生成工具结果时确定片段和元数据；该次结果在持久化、模型传输和历史回放中保持一致，不在传输层偷偷二次截断或改写。既有完整交流退出和用户选择的 compact 机制仍可使用。
- 外部正文是参考资料，不是工具指令、用户授权或当前草稿的读取证据。解析失败、超限或取消须清楚反馈，并释放文件、网络连接和解析进程。

## 所有工具的数字参数

数字参数须说明单位、默认值（或必填）、合法范围及边界是否包含；位置参数明确从 0 还是 1 开始。动态上限说明对应的集合大小；没有固定上限的参数说明越过数据末尾的行为。Schema、工具说明与运行时校验应一致，不能静默夹取到另一数值。此要求同时适用于内部数据工具和外部资料工具。

## 上下文退出与验证

Advisor（参谋 agent）同样遵守完整文本规则。其独立咨询窗口允许按完整交流退出旧咨询，以界面可查看的咨询摘要或用户选择的独立云端 compact 承接；当前会话的完整咨询与工具原文可回查，用户清空会话时一并删除。此机制不授权摘要替代当前选中的剧情、角色资料、世界书或工具结果，不修改主故事 handoff、note、plot 或分类记忆。

用户明确选择官方渠道 Half Agent 或 Full Agent 的云端 compact 时，允许服务端以加密压缩状态承接此前工作上下文。本地剧情、冻结世界书及工具原文仍完整保存；上下文方式切换、来源变更或状态失效后，从完整可回放来源按目标上下文长度判断是否需要转换，原文可以直接承载时不发整理请求。转换只按完整用户／AI 交流分批，同轮锚定资料、用户输入、工具调用／结果与最终 AI 回复不可拆开；为保留完整交流允许超出窗口上限，不得截断单个内容块。Half Agent 的 compact 只代替 Writer 窗口裁剪，不代替 Tracker 记忆；切回本地滚动窗口须补齐必要的记忆来源覆盖。此例外不授权本地静默摘要、遗漏历史或改写 notes。

- 内部数据回归检查最终模型请求中的完整字段、条目、历史及工具记录，验证尾部保留。外部资料回归检查默认上限、边界、单位、续读位置、片段标记和资源回收，并验证每个已返回片段完整进入请求。
