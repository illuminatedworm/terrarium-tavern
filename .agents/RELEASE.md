# 长期使用与发行

本文件约束日志与缓存生命周期、清理、升级、打包发行及发行前验收。操作说明见 [维护](../docs/guides/maintenance.md) 和 [验证说明](../docs/development/validation.md)；版本号见 [版本号基准](VERSIONING.md)。

## 数据生命周期与升级

- 任务对象、详细日志及派生索引应有明确生命周期和容量约束；沿用可配置的日志保留与缓存限额。
- 清理保护活跃、待审核和可恢复回合；剧情、分支及恢复快照不作为日志或旧版本自动删除。
- 清理提供占用与预览，校验真实路径边界。升级先备份，数据库在任何写入前检查格式；不支持的版本不得被修改。

## 打包与发行前验收

- 发行使用白名单、锁文件、文件清单、校验值和第三方许可，排除用户数据、密钥、模型权重及开发环境。
- 发布前验证构建、干净依赖安装、Windows 启停、无 GPU 基础运行、备份恢复和包内隐私边界。
- 布局验收（发行前或用户要求时）：桌面端 2560×1440 与 1920×1080、移动端 1080×2376 设备像素（按设备像素比折算 CSS 视口）及 200% 缩放。
- 全量与打包检查仍受 [AGENTS.md](../AGENTS.md) 测试执行纪律约束：每个任务最多一次，放在最后。

发行命令：`npm.cmd run build`、`.venv/Scripts/python.exe -m tests.browser.browser_release`、`.venv/Scripts/python.exe tools/package_release.py`。
