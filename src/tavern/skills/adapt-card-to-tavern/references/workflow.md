# 工作流与数据契约

Writer 生成叙事和检索线索；Tracker 的独立 MVU 调用接收当前变量、最近 6 条历史、本轮输入/正文与全部启用变量规则。勾选“本轮更新变量”才执行。后台输出 JSON Patch 数组，路径相对于 stat_data，如 `[{"op":"replace","path":"/能量","value":4}]`。变量结果不进入正文，最终由 Runtime 原子提交。

世界书原始条目用途写入 `extensions.terrarium.audience`：
- `writer`：普通叙事设定，默认值；沿用常驻和检索规则。
- `tracker_mvu`：定义、更新条件、约束与输出规则；只在变量更新时全部注入。
- `runtime_init`：InitVar YAML 数据，只供确定性初始化；不进入模型请求。禁用条目不初始化。

开场及其内联 MVU 默认保持原样，不属于本适配流程的完成条件。原卡用于从模型提示中隐藏变量块、初始化变量或渲染状态栏的正则也应保留。只有用户明确要求迁移开场时才使用 `set_opening(index,narrative,initialization)`；迁移前必须读取全部开场与已有独立初始化，并保留模板宏和初始化顺序。稳定身份和内容指纹由程序管理，不得猜测、计算或回写。

JSON Patch 工具路径相对于角色卡完整文档；有 spec 的卡使用 /data/...。世界书支持数组和对象，使用工具返回的 JSON Pointer，其中 @D 短编号由程序恢复为原键。保留未知扩展字段、资源引用、开场顺序；身份及隐藏的指纹由程序保留。新增世界书条目省略ID。不要禁用所有脚本来通过检查：schema 和校验回调可能仍为必需。

完成判定：Writer 与 Tracker 规则已正确分流，世界书初始化数据未丢失，无待处理问题。开场及其 MVU 内容默认不纳入完成判定。`validate_draft` 检查结构与 Writer 条目中的常见残留，无法证明任意脚本的语义等价，报告中必须区分静态检查与实际运行验证。
