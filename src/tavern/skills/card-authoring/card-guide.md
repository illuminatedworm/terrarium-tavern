# 从零制卡

本指引给出创作思路与制作顺序。字段格式、注入位置和世界书字段见 `card-format.md`；用户需要变量、正则或脚本时另读 `runtime-guide.md`。

## 制作顺序

1. **收集**：弄清题材与基调、卡的类型（单个人物、多人群像、世界／情境）、用户扮演谁及与角色的关系、互动方式（日常、冒险、悬疑、经营等）和尺度边界。用户已说明的直接采用，缺口只问会改变方案的几项。
2. **方案**：按下方模板写简短方案，等用户确认或修改。基于原著或真实资料时注明来源，改编处与用户确认。
3. **分配内容**：按“内容放在哪里”决定每条设定的位置。
4. **写正文**：`create_draft` 的 `fields` 一次写入 description、personality、scenario、first_mes、alternate_greetings、mes_example 等完整正文。
5. **写世界书**：读取 `card-format.md`，再用 `patch_draft` 向 `/data/character_book/entries/-` 追加条目，条目多时分批。
6. **检查**：运行 `validate_draft` 并按完整性提示补齐；对照方案核对开场数量、世界书清单、视角与人称。
7. **交付**：用户提供头像图片并说明用途时用 `set_portrait`。最终回复概括卡片结构、开场与世界书条目，列出待用户决定或验收的部分，提醒审阅后保存。

方案模板：

```text
定位：单人人物卡。退役剑士林默在边境小镇经营旅店，核心冲突是旧日战友带来的追杀令。
用户角色：初到小镇的旅人，与林默素不相识。
互动方式：日常经营为主，逐步揭开过去，可转入冒险。
风格：克制、写实，第三人称过去时，每次回复约 300 字。
开场：3 个——雨夜投宿、旅店遭砸、集市偶遇。
世界书：小镇、莉娅（旧战友）、追杀令、林默的佩剑，共 4 条，均按关键词触发。
机制：无。
```

## 内容放在哪里

| 内容 | 位置 | 判断依据 |
|---|---|---|
| 身份、处境、动机、对 {{user}} 的初始态度 | description | 每轮都需要的核心 |
| 行为与反应方式、说话习惯 | personality | 每轮都需要 |
| 当前互动的时间、地点、前因 | scenario | 每轮都需要 |
| 语气、叙述风格、回复长度 | mes_example | 用示范代替描述 |
| 只在提到时才需要的人物、地点、势力、物品、历史 | 世界书，关键词触发 | 情境性资料 |
| 所有对话都要遵守的少量世界规则 | description 或常驻条目 | 常驻内容每轮占用 token |
| 写作要求（视角、尺度、文风） | system_prompt | 确有必要时 |
| 每轮最后提醒的要点 | post_history_instructions | 位于当前输入之后，影响最强，保持简短 |
| 给读者的介绍、游玩建议 | creator_notes | 不进入游玩请求 |

同一信息只在一处完整写出，其他位置需要时引用名称即可。默认制作完整文本卡：设定、可互动的开场、示例和必要的世界书；剧情中发生的变化由运行时记忆维护，卡片只写稳定设定。

## 人物卡

description 写清身份、有辨识度的外貌、当前处境、想要什么与害怕什么、对 {{user}} 的初始态度及原因。personality 用可观察的行为写性格：面对压力、被冒犯、被关心时分别怎么做，口癖与说话节奏，绝不会做的事。给人物留出内在矛盾或秘密，让关系能够推进。

## 世界与情境卡

description 写世界的基本规则、当前局势和用户能介入的入口；主要人物、地点、势力、物品和历史放进世界书。世界卡中的 {{char}} 通常是叙述者或世界本身，在方案中写明，开场和示例保持同一视角。多人群像卡为每个主要人物写一个世界书条目，description 只保留人物关系总览。

## 开场

first_mes 交代时间、地点与氛围，让角色先行动或开口，结尾留下用户可以回应的空间。{{user}} 的言行和感受留给用户。多个开场提供不同切入点（关系阶段、地点、事件），各自独立成立。篇幅与预期回复长度相当。

## 示例对话

mes_example 用 `<START>` 分隔若干段，以 `{{user}}:`、`{{char}}:` 标注说话人，展示“怎么说”：

```text
<START>
{{user}}: 这把剑看起来很旧了。
{{char}}: 林默擦杯子的手停了一下。"旧东西结实。"他把杯子倒扣在架上，没有看你，"房钱先付，热水自己打。"
```

示例内容与开场不同，也不写成已经发生的剧情。

## 世界书

- 每个条目只讲一件事（一个人物、地点、势力、规则或事件），正文自足，第一行写明主体及常用称呼。
- `comment` 写条目标题；`keys` 写正文中会自然出现的名称、别称和关键词；必须同时满足的限定词放 `secondary_keys`。
- 只有所有对话都必须知道的少量核心规则设为常驻。
- 变量规则与初值按 `runtime-guide.md` 设置用途。
- 多张卡共用的设定适合做成独立世界书（用户新建对话时挂载），只属于这张卡的设定写进卡内世界书；不要为了“引用”在两者之间复制条目。

## 交付前自查

- 开场和示例中没有替 {{user}} 说话、行动或决定感受。
- 性格写成了可观察的行为。
- 多个开场切入点不同，彼此不引用。
- 示例没有复述开场。
- 同一设定没有在 description 和世界书各写一遍。
- 关键词避开“他”“城市”这类泛词；两字人名出现在正文第一行。
- 用户以 `{{user}}` 指代，没有写死名字；各字段人称、时态和设定一致。
