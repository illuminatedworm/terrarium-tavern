# 参谋 agent 聊天

Half Agent 和 Full Agent 都可从右侧栏的“参谋”打开参谋 agent，用于回顾剧情、查阅设定、检索外部资料、讨论故事走向或咨询普通问题。咨询与剧情分别保存。

## 配置模型与提示词

在“设置 → 通用 → 参谋 agent”分别配置普通 API 和 ChatGPT 官方渠道。参谋 agent 使用独立模型，渠道与当前故事一致；侧栏模型选单可为当前故事选择同渠道供应商和模型，或恢复全局配置。

系统提示词可编辑，保存后用于后续咨询。“恢复默认文本”先填入编辑框，再保存生效。默认提示词说明主故事、记忆、规划和偏好的用途；工具权限由运行时管理。

## 自动带入与按需查阅

默认参考最近 **3 次完整交流**，范围为 **0–1000 轮**，0 表示关闭。全局默认在设置页修改，当前故事可通过“参考最近 N 轮剧情”覆盖；入口显示生效来源，“使用全局默认”清除故事覆盖。

| 资料 | 提供方式 |
|---|---|
| 人物、场景、用户角色、常驻世界书、本轮偏好 | 自动提供完整内容 |
| 近期剧情及其已注入世界书 | 按完整、已提交的交流提供，短历史可包含开场 |
| Half Agent 分类记忆 | 自动提供当前有效记录 |
| Full Agent 交接笔记 | 本地换窗模式自动提供当前版本 |
| 更早剧情、长期笔记、剧情规划、详细变量 | 按需通过工具检索和读取 |

“查看上下文”展示已保存背景、咨询消息、工具和估算用量。当前输入框的问题在发送后加入请求；云端加密状态的占用以服务商返回为准。

每次咨询固定使用开始时的剧情快照，下一次咨询刷新背景。回退、重生成或编辑来源后，旧讨论会标记依据变化。每个故事保留一份参谋会话；分支继承模型与范围设置，并从空白咨询开始。

## 清空、长对话与恢复

“清空对话”经确认后永久删除当前咨询、摘要、工具记录、云端状态和未完成进度，保留故事、已保存偏好及参谋设置。正在回答时先停止。切换故事、关闭面板或重启后，已保存咨询仍可继续。

上下文超出参谋模型容量时，默认整理旧咨询并保留最近 **4 次咨询**原文。保留轮数和自动整理可在设置中调整，也可在范围设置中点击“立即整理旧咨询”。普通 API 使用可查看的咨询摘要，官方渠道还可选择独立云端 compact。

整理按完整交流进行，原始咨询与工具结果保留供回查；本轮选中的剧情和资料保持全文。来源、模型、账号或关键提示词变化时，从原文重建整理状态。仍超出容量时会提示，并完整提交请求，由服务商接受或拒绝。

停止、网络失败和调用额度耗尽时保留进度，可继续或丢弃。每次发送或继续默认最多 **24 次模型请求**，包括咨询整理。已成功的工具结果可续用；关闭面板后后端继续运行，再次打开即可查看进度。

## 修改本轮偏好

明确要求修改偏好时，例如“把保持悬念加入本轮偏好”，参谋 agent 会暂存修改，咨询正常完成后与结果一同保存，并同步偏好编辑框。普通讨论只保留在咨询中。

提交时检查故事版本、偏好原值和运行状态。正文生成、待审核、上下文整理或同时手工修改偏好造成冲突时，会保留待处理进度。参谋 agent 对主故事的写入范围限于已授权的本轮偏好，其余故事资料供查阅。

本轮偏好持续生效，直至用户或获得明确授权的参谋 agent 再次修改。

## 外部资料与数据保存

在“设置 → 通用 → 联网服务”配置与角色卡编辑 agent 共用的服务、顺序、密钥和超时。默认顺序为 Exa MCP、Tavily、已配置的 SearXNG、DuckDuckGo。Exa 和 Tavily 支持免 key 接入或自有 API Key，额度及计费以服务商实际规则为准。应用只回显密钥配置状态，默认导出排除密钥。

参谋 agent 的“联网方式”可选关闭、自动或本地实现。自动模式下，ChatGPT 官方渠道优先使用云端搜索，普通 API 使用共享本地服务；本地实现由应用发起互联网请求。搜索故障可按策略换用本地服务，账号或额度问题需处理对应连接。

工作记录显示实际服务和失败原因。本地搜索返回限量摘要，网页默认每页 **12,000 字符**、最多 **30,000 字符**，续读沿用返回的服务和偏移。来源可能只提供部分正文，完整性标记及详细参数见[联网工具协议](../reference/web-tools.md)。外部资料作为咨询参考，使用应用通用网络设置。

咨询随故事删除。故事导出携带参谋设置，完整目录备份还包含当时的咨询与已停止进度。诊断日志按保留策略清理，当前咨询通过“清空对话”管理。

工具和存储契约见[参谋 agent 设计](../design/advisor.md)。
