# 参谋 agent 聊天

Half Agent 与 Full Agent 都可以从右侧栏的“参谋”标签打开参谋 agent。参谋 agent 是独立的聊天助手，可以回顾剧情、查阅世界设定、咨询原著资料、讨论下一步，也可以回答普通问题。讨论本身不会推进故事。

默认提示词说明参谋 agent 与主 Agent 位于同一界面，将“左边对话”“主对话”“游玩对话”“full / half agent”“正文”等用户称呼关联到主角色扮演上下文；需要历史细节时仍通过工具补查。

## 配置模型与提示词

在“设置 → 通用 → 参谋 agent”分别配置普通 API 和 ChatGPT 官方渠道的模型。参谋 agent 可以使用与正文完全不同的供应商和模型，但必须与故事属于同一渠道；不会自动借用正文模型。侧面板的模型选单可以为当前故事覆盖供应商与模型，或恢复全局配置。接口方式、生成参数与消息适配在参谋 agent 设置页配置。

参谋 agent 系统提示词可以编辑并显式保存。“恢复默认文本”会填入当前默认提示词，点击“保存”后生效。默认提示词解释 handoff、note、plot、分类记忆和本轮偏好的用途与事实性质，不要求参谋 agent 了解游玩模式的内部名称，不强制输出选项，也不设置固定剧透等级。可用资料以实际上下文和工具结果为准。升级仅替换完全一致的旧默认提示词，已有自定义内容保持原样。实际工具权限由 Runtime 控制，自定义提示词不能开放故事写入工具。

## 自动带入与按需查阅

默认自动带入最近 **3 次完整交流**，支持 0–1000 轮，0 表示关闭。全局默认在设置页修改，当前故事可以从“参考最近 N 轮剧情”覆盖，入口显示生效来源。“使用全局默认”会清除故事覆盖。开场在历史较短时一并提供；未完成交流、未发送输入和待审核正文不会自动带入。

基础人物与场景资料、用户角色、常驻世界书、本轮偏好以及近期交流对应的已注入世界书完整提供。Half Agent 携带当前有效分类记忆；Full Agent 本地上下文携带当前 handoff。notes、plot 和详细变量可以按需读取。更早的当前分支剧情仍可通过工具检索和完整回读。

“查看上下文”展示下次咨询背景、消息、工具和估算 token 数，不包含尚未发送的问题。未知模型明确使用参考分词器；云端密文的实际占用无法本地估算。预览只读，不发维护或模型请求。

每次咨询使用开始时的剧情快照，下一次咨询刷新背景。故事回退、重生成或编辑来源后，旧讨论会标记依据已变更。每个故事只保留一份参谋会话；新建分支沿用模型与范围设置，但从空白咨询开始。

## 清空、长对话与恢复

参谋会话是临时工作区，不提供多会话管理或历史归档。面板顶部的“清空对话”经确认后删除聊天、咨询摘要、云端上下文、工具记录和未完成进度，无法撤销；模型与范围设置、故事正文、已保存的本轮偏好保持不变。正在回答时须先停止。切换故事、关闭面板或重启不会主动清空当前会话。

参谋 agent 默认在超过其模型容量时整理旧咨询，保留最近 **4 次咨询**原文；保留轮数和自动整理开关可配置。普通 API 使用可查看的咨询摘要，官方渠道还可选择独立云端 compact。范围设置中提供“立即整理旧咨询”。摘要属于参谋 agent 聊天，不写入故事 handoff、note 或 plot。

整理按完整咨询交流进行，原始咨询和工具结果仍可回查；当前选中的剧情、设定、工具结果不会截断。没有可退出的旧咨询时保留完整请求并提示超量，服务商拒绝会显示错误。模型、账号、关键提示词或已覆盖剧情变化使旧整理状态失效，从原始记录重新编译。

停止、网络失败和调用额度耗尽保留未完成进度，可继续或丢弃。每次发送或继续默认最多 24 次模型请求，包括咨询整理；不会向模型注入倒计时。切换故事或关闭面板不自动取消后端任务；留在当前故事时，隐藏面板仍可接收完成事件并同步偏好。重启后通过“继续咨询”恢复，成功工具调用不重复执行。

## 修改本轮偏好

参谋 agent 只能在用户明确要求时修改本轮偏好，例如“把保持悬念加入本轮偏好”。“这样发展怎么样”仅属于讨论。

修改先暂存，咨询正常完成后与结果一起保存并同步现有偏好编辑框。失败、停止或丢弃不会部分生效。故事版本变化、用户同时手改偏好、正文正在生成、待审核或正在整理故事上下文时，写入会被拒绝。参谋 agent 不修改变量、角色卡、世界书、handoff、notes、plot 或分类记忆。

本轮偏好沿用现有会话语义：持续生效，直到用户或获明确授权的参谋 agent 再次修改，不自动在一轮后清空。

## 外部资料与数据保存

联网工具默认使用无需密钥的 DuckDuckGo HTML 搜索，也可配置支持 JSON 搜索的 SearXNG 服务。网页读取返回完整提取文本及来源；只支持 HTML 和文本，超过 8 MiB、登录要求、验证或网络失败均明确报告。外部资料不自动覆盖世界卡或本局事实。网络使用应用通用网络设置。

咨询随故事删除。故事导出仅携带参谋 agent 的故事级设置，不携带聊天或进度；导入旧包时也不恢复其中的咨询记录。完整目录备份仍作为数据目录快照保留当时的咨询与已停止进度。普通日志清理仅回收已结束且无待续进度的诊断，当前咨询通过“清空对话”统一丢弃。
