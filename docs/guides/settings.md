# 设置与模式隔离

设置按 full agent、half agent 和通用资源分组。菜单中的正文生成、后台整理分别对应代码中的 Writer、Tracker；角色卡编辑是独立于剧情的编辑模型。

## 两套独立参数

两种模式分别保存模型、预算、采样、提示缓存、适用提示词、检索规则、世界书额度和默认对话更新策略。full agent 不继承 half agent 的模型或参数；half agent 内的正文生成和后台整理也分别配置模型。

模型高级设置中的缓存控制只有“云端默认”和“本地运行时控制”。正文模型默认由本地每新增 5 轮推进一次断点，每次定位到倒数第 3 个已完成 AI 回复，支持在对话中手动固定；目标回复不足或尚未首次跟进时使用固定前缀。参数按模型和协议匹配，也可编辑字段名、JSON 值及附加请求参数。Gemini 缓存对象由运行时管理，无需填写资源 ID。服务商不支持时会明确显示云端降级，断点标记不代表实际命中。

提供商可选择 Chat Completions、Responses、Anthropic Messages 或 Gemini GenerateContent。模型页显示实际生成路径；更换协议不会自动修改模型名称或接口地址。详细行为见[统一提示缓存](../design/cache-control.md)。

切换模型名称不会自动切换提供商的接口协议。右侧缓存页显示当前已保存的正文模型与接入方式；模型名称和原生协议不属于同一家时会提示缓存仍按接入协议匹配。例如 Gemini 模型经 Anthropic Messages 接入时，仍提供 Anthropic 的 5 分钟／1 小时档；改为 Gemini 接入后才提供 Gemini 对象时效。保存模型或提供商协议后，当前对话页面立即更新档位，不需要重新建对话或刷新页面。

自动缓存预设也遵守协议边界：Claude 经 Responses 接入时不发送 Anthropic 内容块标记；旧 o1/o3/o4 系列使用服务端自动前缀缓存和内存保留参数，不发送新版 GPT 显式断点。自定义格式仍由用户配置，服务商拒绝时按既有规则提示或降级。

右侧“缓存”页可选择正文模型的缓存时效，保存到当前模式的模型配置，影响该模式所有会话，从下一次请求生效。新配置默认最低档；切换模型后，原档位不适用时使用新模型的最低档。Claude 原生及 Chat 兼容路径提供 5 分钟／1 小时；Gemini 原生及 Google Chat 兼容的显式对象提供 5 分钟／15 分钟／1 小时／24 小时这些应用预设。OpenAI Chat／Responses 按模型区分：GPT-5.6 及以后目前只有 30 分钟档，GPT-5.5 只有 24 小时档；更早且支持扩展保留的模型提供内存缓存／24 小时，其余仅内存缓存。未知协议或自定义断点格式不假定支持时效控制。服务商仍可能拒绝参数，选择档位不保证命中。Claude 原生云端模式在用户保存时效后使用顶层自动缓存，服务端选择缓存终点；Claude Chat 兼容与 Gemini 隐式云端模式不传入时效。OpenAI 云端模式仍可传入时效，不注入本地断点。

工具循环、换窗、交接与长期笔记属于 full agent。历史裁剪、周期整理、分类记忆和上下文编排属于 half agent。full agent 固定随对话注入世界书。

提供商连接和密钥、本地模型选择与文件、代理、日志与缓存容量由两种模式共用。检索任务提示词、重排提示词、重排开关及片段数量属于各模式的独立运行参数。修改共用提供商会影响所有引用该连接的模型；删除前必须先解除引用。

## 保存和撤回

- 保存成功提示停留 2 秒后用半秒渐隐，再次修改会重新显示；保存中、失败及未保存状态不会自动隐藏。
- 普通输入停止 600 毫秒后自动保存，开关与选择项立即排队保存。关联约束不满足时保留草稿并显示错误，不写入部分配置。
- 大文本修改后出现绿色勾按钮，点击或使用 `Ctrl+Enter` 保存该文本。放大编辑采用同一规则；恢复默认文本后也需明确保存。
- 离开未保存文本时，只提供“继续编辑”和“放弃修改”。放弃只清除未保存草稿，不撤销已成功保存的普通参数。
- “撤回本页修改”恢复本次打开设置时该页的值，支持恢复已改动的密钥，但不会将原密钥返回浏览器。不会撤回已执行的生成、下载、预热或清理任务。
- 编辑快照保留在服务端内存中，关闭设置即释放，闲置两小时过期。刷新或退出不保证保留未保存草稿。多窗口修订冲突会拒绝覆盖，需重新打开设置后处理。

保存成功后的下一次操作采用新配置，已经运行的回合继续使用开始时的配置快照。未单独设置权限的对话动态继承对应模式的默认策略；扩大默认权限同样从下一轮生效。上下文编排和 half agent 的注入方案仅复制给新对话，已有对话继续使用自己的设置。

会话设置中的“本轮偏好”和重新生成时的“补充要求”会显示当前模式配置的系统预制头；本轮偏好的放大编辑窗口也显示同一预制头。此区域只读，编辑和保存只涉及用户填写的部分。需要修改预制头时，在对应模式的提示词设置中修改“对话偏好引导词”或“重新生成引导词”。

应用提示词统一将参与游玩的人类方称为“用户”。启动时会将已保存应用提示词中的“玩家”及英文 player 统一替换，并更新受影响模式的修订号；其余定制文本、用户角色名称、角色卡和历史正文保留原样。重复启动不重复增加修订号。

## 升级与接口

首次升级会在写入前检查版本、备份原数据库为数据目录中的 `settings-before-v2-*.sqlite3`，随后事务提交设置和数据库版本 2。保留原连接、密钥和自定义文本；曾经继承模型的 full agent、角色卡编辑，按升级前实际生效值复制为明确的独立配置。原共用运行参数深拷贝到两套配置。重复启动不会再次覆盖，未知版本拒绝写入。

本次升级不承诺旧版对话兼容，不删除原数据文件。旧程序不能打开新数据库，需要回退时使用升级前备份。

`GET /api/settings` 返回版本化的 `full_agent`、`half_agent`、`shared`、各范围修订号及页面／提示词目录，不再返回顶层写作模型投影。密钥仅返回 `has_api_key`。

`PATCH /api/settings/{scope}` 提交 `expected_revision` 和 `changes`。`changes` 使用相对字段路径，例如 `{"model.reply_tokens": 4096}`；数组整体更新。提供商密钥留空或省略表示保留。旧扁平 `PUT /api/settings` 已移除。

`POST /api/settings/edit-sessions` 返回编辑标识和当前设置。更新可携带 `edit_session`；`POST /api/settings/edit-sessions/{id}/undo` 使用页面标识和预期修订号撤回该页，`DELETE` 同路径释放编辑快照。修订冲突返回 409，校验失败返回 400；错误不回显提交的密钥。

验证入口：后端 `test_settings_document.py`、前端 `settingsDocument.test.ts`，浏览器 `python -m tests.browser.browser_settings` 和 `python -m tests.browser.browser_prompt_prefixes`。所有检查使用隔离数据和本地模拟模型。
