# 角色卡编辑与工作流适配

角色卡列表和编辑页可复制已保存角色。副本拥有新 ID 和独立文档，名称自动添加“（副本）”及编号；头像、CHARX 资源、脚本权限和已缓存依赖保留，底层文件按哈希共享。删除原卡不会删除仍被副本、编辑草稿或对话使用的资源。

世界书可搜索名称、注释、ID、主／副关键词和正文；空格分词后同时匹配，不区分大小写。启用状态、触发方式和条目用途可组合筛选。筛选不改变原始顺序，显示“匹配数 / 总数”。对话侧栏“场景 → 编辑对话世界书”使用同一编辑界面，仅保存当前对话的设定；预览策略下需接受修改后生效。

## 独立编辑 Agent

同一张角色卡可以有多个独立编辑对话。Agent 工作区顶部的“编辑对话”选择器用于切换，显示首条要求和运行状态；刷新后恢复选中的对话。

- **新建对话**：从角色卡库中最新已保存的版本创建空对话，不带入旧聊天、工具记录或未保存草稿。
- **沿用草稿开新对话**：复制当前已完成的草稿，创建全新聊天上下文；旧对话、草稿和撤销记录保留在原处。若旧任务仍在运行，使用它上一次完成的草稿，不复制本轮临时修改。
- 各对话的草稿、聊天、工具记录和未发送输入相互独立。切换离开不取消后台任务，旧任务的返回结果不会覆盖当前视图。
- 沿用草稿时保留原卡的基准版本；若另一对话已保存原卡，旧基准保存会提示冲突，可重新载入原卡或另存副本。


打开角色卡的“Agent 编辑”，输入修改要求，或点击“适配本项目工作流”。未保存的表单内容会作为草稿起点。模型设置可启用独立 Card Editor 配置；关闭独立配置时完整沿用后台 Tracker 模型、思考参数与预算。

Agent 与剧情无直接关系，不读取对话、记忆或当前变量。它只拥有卡片概览、分页读取、搜索条目、JSON Patch 草稿修改、开场迁移、静态验证及内置 skill 读取工具；没有 Shell、任意文件、网络浏览或自动保存原卡工具。单轮最多 12 次模型调用，最后一次仅汇报；连续编辑时提供最近已完成的编辑交互，当前草稿始终可通过工具读取。

模型读取的是可逆精简视图：长身份和不透明路径键改为本轮 @D 短编号，指纹/哈希不展示。程序在应用 JSON Patch 前恢复原键和真实身份，替换父对象时保留隐藏字段；新增世界书条目无需模型生成ID。分页发生在投影之后，错误及后续工具请求也不能带回内部长ID。仅当用户明确要求编辑或迁移开场时才使用 `set_opening` 管理关联和指纹。详情见[模型数据边界](../design/model-data-boundary.md)，原始JSON表单和存储格式不变。

点击“Agent 编辑”后进入独立对话工作区：主区域展示编辑要求、Agent 回复和按顺序记录的模型请求／工具动作，底部输入框固定，支持 Enter 发送、Shift + Enter 换行。读取字段、搜索条目、读取 skill、修改草稿和验证均记录开始、完成或失败；展开动作可查看输入、结果预览和耗时。预览上限为 4000 字符，不把完整模型请求加入动作列表。刷新后可恢复动作记录；早期或已清理的记录会提示没有可用详情。

右侧标签页分别为“角色数据”“诊断”“修改”。数据树默认全部折叠，按需渲染子节点，支持一键折叠；诊断展示结构检查、适配问题和工具异常；修改页查看字段／条目的前后差异并执行保存、撤销等操作。窄屏通过“角色资料”打开侧栏，主区域和侧栏独立滚动。运行中的数据树显示上次完成的草稿，失败或取消不会应用本轮临时修改。

编辑结果写入独立工作区，按字段／世界书条目查看修改前后。可切回手工表单修改、撤销上一轮、删除编辑对话、覆盖原卡或另存副本。覆盖保存需要原卡 revision 匹配；冲突保留草稿，可另存。刷新页面会恢复草稿与已完成编辑记录，运行任务可以重新观察；SSE 断线不取消任务。停止、异常和服务重启不会把半轮工具修改写进草稿，保留上一个完整版本。

## MVU 用途与初始化

条目的 `extensions.terrarium.audience` 支持：

| 值 | 用途 | 注入规则 |
|---|---|---|
| `writer` | 叙事设定（默认） | 原有常驻、关键词、BM25、向量和递归准入 |
| `tracker_mvu` | 变量定义、更新条件、约束 | 仅勾选“本轮更新变量”时，全部启用条目按原顺序送入 Tracker 的 MVU 请求 |
| `runtime_init` | InitVar YAML 数据 | 仅确定性初始化，不进入模型请求 |

用途同时约束候选检索、显式读取、常驻注入、旧冻结记录和最终编译。后台记忆整理与设定维护不因标记额外接收 MVU 规则。变量规则展开宏后计数，在“后台工作记录 → MVU 变量”查看注入条目、内容、哈希版本和 tokens。超出后台上下文预算时阻止请求，不截断必要规则；正文草稿保留，整轮不提交。

默认适配不修改开场、内联 MVU 初始化/更新块或配套的提示词过滤与状态栏正则，也不要求创建 `extensions.terrarium.workflow`。因此原卡既有的开场初始化和显示行为保持不变；静态适配完成判定只检查 Writer/Tracker 分流与世界书初始化。用户明确要求迁移开场时，才通过 `set_opening` 将叙事与独立初始化记录关联，并由程序维护稳定 id 与正文指纹。

显式迁移的初始化只允许 InitVar YAML、JSONPatch 和受限 MVU 数据指令，不执行模型生成的任意 JavaScript。世界书提供默认值，所选开场的 InitVar 值优先，再执行独立开场更新；未迁移卡继续沿用原开场初始化方式。

内置 skill 见 [adapt-card-to-tavern](../../src/tavern/skills/adapt-card-to-tavern/SKILL.md)。普通润色不自动触发适配，默认适配也不触发开场迁移。混合叙事与变量的世界书条目需要拆分，原叙事保留原 ID，新规则记录 split_from；保留未知扩展、schema 与校验回调。无法可靠处理的动态脚本保留原状并报告人工核对项。静态验证无法证明任意脚本的语义等价；真实模型适配质量需要另行实测。

## 保存、版本与维护

角色卡使用 revision 管理并发修改；对话拥有独立角色资料。编辑工作区保存草稿、撤销记录、任务、事件和幂等保存记录。新故事创建时固定所用角色资料。库内保存、复制、删除不再改变已有对话的设定；分支内已有设定覆盖保持优先。脚本权限同样属于对话创建时的资料。

角色卡更新 API 要求 expected_revision。复制使用 `POST /api/cards/{cid}/copy`；独立编辑会话通过 `/api/cards/{cid}/edits` 与 `/api/card-edits/{id}` 创建、恢复、更新、撤销和保存；`POST /api/card-edits/{id}/new-context` 使用 expected_revision 校验并从完成的草稿创建空上下文；运行任务与 SSE 使用 `/api/card-edit-runs/{id}`，`/activity?after=序号` 分页读取动作记录，`/events` 实时观察并支持重连。保存指定 overwrite/copy 和 operation_id，防止重复另存。

编辑会话及草稿随 SQLite 备份，资源引用参与清理保护。运行编辑期间禁止备份或清理；未保存草稿、撤销历史与编辑对话不自动清除。已保存工作区的详细诊断事件按日志保留天数和容量上限清理。删除编辑对话会移除该会话、草稿、动作记录、撤销历史和本机未发送输入；源卡删除后草稿仍可另存副本，从角色卡列表下方“原卡已删除的编辑草稿”继续编辑。

完整 source 发行包和 Python 包均包含内置 skill，不依赖开发者个人 Codex skill 目录。

## 删除编辑对话与未保存修改

工作区顶部提供“删除编辑对话”，修改页也可删除当前对话。确认窗口会说明是否有未保存修改：

- **不保存，删除对话**：删除该对话及其草稿。若修改只存在于这份草稿里，就会丢失；不会替用户自动保存原卡。
- **覆盖保存后删除**：先保存角色卡，成功且草稿版本未再改变时才删除对话。
- **另存副本后删除**：先建立保留修改的新角色卡，再删除对话；原卡保持不变。
- **取消**：保留对话和草稿。已保存的角色卡、其他编辑对话中的独立草稿，以及游玩对话均不因删除当前对话而改变。

运行中需先停止任务。保存失败、原卡版本冲突、草稿在保存后又被修改时不继续删除。删除后优先切到该卡剩余的编辑对话；没有剩余对话时返回已保存的角色卡。原卡已删除的草稿也可以先另存副本再删除。
