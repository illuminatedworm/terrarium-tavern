# 编辑角色卡与适配工作流

书架角色卡是创建新故事的模板；已有故事保存自己的角色资料。修改、复制或删除书架卡片不会改变已有故事。当前故事的设定应从对话侧栏“场景 → 编辑对话世界书”修改，预览策略下需要接受后生效。

## 手工编辑与复制

角色卡列表和编辑页可以复制已保存角色。副本有新的身份和独立文档，名称添加“（副本）”及编号；头像、CHARX 资源、脚本权限和已缓存依赖保留。共享底层文件不会让副本跟随原卡变化，删除原卡也不会删除仍被引用的资源。

PNG 角色卡的图片和 CHARX 中声明的内嵌头像会显示在角色卡列表、编辑页、新故事的角色选择与开场设置、会话列表及对话头像中。没有图片或图片加载失败时显示角色名字首字。已有会话使用创建时保留的图片，修改或删除角色库中的原卡不会改变该会话的头像。

世界书可搜索名称、注释、ID、主／副关键词和正文。空格分词后同时匹配，不区分大小写；启用状态、触发方式和条目用途可以组合筛选。筛选保留原始顺序，并显示匹配数与总数。

“脚本与兼容”页列出全部正则脚本与 Tavern Helper 的顶层、分组及旧版角色脚本，包括停用项。可以编辑匹配表达式、替换内容、脚本正文和原始参数；世界书初始化内容仍在对应条目中查看。

## 使用 Agent 编辑

1. 在“设置 → 通用 → 角色卡编辑”配置独立模型。
2. 打开角色卡的“Agent 编辑”，输入修改要求，或点击“适配本项目工作流”。未保存的表单内容可以作为草稿起点。
3. 查看模型回复和工具动作；展开动作可检查输入、结果预览与耗时。
4. 在右侧“角色数据”查看草稿，在“诊断”查看问题，在“修改”比较前后差异。
5. 审阅后选择覆盖原卡或另存副本。也可以返回表单修改，或撤销上一轮。

Agent 不读取游玩剧情、记忆或当前变量，只修改编辑草稿。单轮最多 12 次模型调用；最终说明不会自动保存书架卡片。停止、失败或服务重启保留上一个完整草稿，不应用半轮修改。

输入框支持 Enter 发送、Shift+Enter 换行。窄屏通过“角色资料”打开侧栏。运行中的数据树显示上次完成的草稿；刷新后可以恢复已完成交互，并重新观察运行任务。切换页面或 SSE 断线不取消任务。

## 管理独立编辑对话

顶部“编辑对话”选择器用于切换同一卡片的工作区，显示首条要求及运行状态。各对话的草稿、工具记录、聊天、撤销历史和未发送输入相互独立。

| 操作 | 起点与结果 |
|---|---|
| 新建对话 | 从最新已保存角色卡建立空聊天和草稿 |
| 沿用草稿开新对话 | 从当前对话上一次完成的草稿建立空聊天，保留原基准版本 |
| 覆盖原卡 | 保存草稿到书架，需要基准 revision 匹配 |
| 另存副本 | 创建新的书架角色卡，保留原卡 |

若另一对话已经保存原卡，旧基准覆盖会提示冲突。先核对新版本，再决定重新载入原卡或另存副本。沿用草稿时，运行中尚未完成的修改不会被复制。

## 世界书用途与初始化

适配工作流主要用于 Half Agent 的叙事与变量分工。条目字段 `extensions.terrarium.audience` 表示：

| 值 | 用途 | Half Agent 行为 |
|---|---|---|
| `writer` | 叙事设定，默认值 | 按常驻、关键词、BM25、向量和递归规则选择 |
| `tracker_mvu` | 变量定义、更新条件与约束 | 勾选本轮更新变量时，将全部启用条目交给 Tracker |
| `runtime_init` | InitVar YAML 数据 | 确定性初始化，不进入模型请求 |

用途影响资料选择；后台记忆与设定维护不会因条目存在就额外接收变量规则。Tracker 按宏展开后的完整规则估算输入，超量时提示并完整发送。服务商拒绝或最终 MVU 校验失败时，正文草稿保留，整轮不提交。

默认适配保留开场及其内联 MVU 块、提示词过滤和状态栏正则。需要迁移开场时，应在要求中明确说明，让专用工具管理叙事与初始化的关联；普通润色不会自动触发适配。

适配后重点检查叙事与变量规则是否正确分开、初始化值是否符合原卡、未知扩展是否保留。静态诊断不能证明动态脚本行为等价，应使用独立测试故事检查。支持范围见[兼容矩阵](compatibility.md)，适配协议见[编辑工作区设计](../design/card-editor.md#工作流适配)。

## 删除编辑对话

顶部和“修改”页均可删除当前编辑对话。确认窗口提供：

| 选择 | 结果 |
|---|---|
| 不保存，删除对话 | 删除聊天和草稿；仅存在于该草稿中的修改丢失 |
| 覆盖保存后删除 | 先保存原卡，成功且草稿没有再次改变时删除 |
| 另存副本后删除 | 先创建新角色卡，再删除工作区 |
| 取消 | 保留对话和草稿 |

运行中先停止任务。保存失败、原卡版本冲突或草稿再次修改时，不会继续删除。已保存角色卡、其他编辑对话和游玩会话保持独立。原卡已删除的草稿可从角色卡列表下方“原卡已删除的编辑草稿”继续编辑或另存。

## 备份与常见问题

编辑对话、草稿及撤销记录属于用户数据，随应用备份保存。未保存草稿不自动清除；已保存工作区的详细诊断遵循日志保留策略。运行编辑任务时不能备份或清理，见[安装与维护](maintenance.md)。

| 问题 | 处理 |
|---|---|
| 保存冲突 | 核对原卡的新版本；保留草稿，选择重新载入或另存 |
| 工具完成但本轮失败 | 检查错误，确认上次完整草稿后重试；临时修改未提交 |
| 诊断没有详情 | 早期记录可能缺失，详细事件也可能已按保留策略清理 |
| 删除原卡后找不到入口 | 查看列表下方的孤立编辑草稿区域 |

开发者可参阅[工作区设计与 API](../design/card-editor.md)。
