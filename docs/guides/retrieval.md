# 世界书检索与最终注入

默认使用关键词和 BM25；可选本地 Qwen3 Embedding 与 Reranker，查询时不会下载或预热模型。
查询取有界的当前输入和最近回复检索线索，空输入或“继续”使用有界本地回退，不扫描完整历史。
检索线索以 tavern_retrieval 区块输出，服务端从正文和 MVU 中分离保存。

## 准入与排序

- 关键词保留大小写、全词、正则和次级条件规则，同时检查词长、主体和常见程度。单字或泛词不能单独放行。
- BM25 使用中/英/日分词与字符二元组排序；要求有效词汇交集、至少 0.25 查询覆盖和 0.35 相对分数。二元组不能独立激活。
- 向量最低余弦相似度默认 0.5。片段聚合为条目，最终注入完整条目。
- 加权 RRF 只融合排序，不是相关性概率。每通道最多 30 个候选，融合最多 20 个。
- 启用重排时，所有普通候选以原始查询重排，默认阈值 0.5；低于阈值后不能经递归重新进入。
- 重排不可用时只保留独立词法证据，不降低门槛、不补满数量。合法零命中不等于系统失败。
- 条目还受启用、时间线、次级条件、概率、冷却和最终预算约束；常驻保留作者语义。

这些分数均不是校准的置信概率，需针对实际卡片评估。

## 递归和滚动

默认开启一层递归，仅本轮直接准入条目可以作为起点，后续层仍须准入。
旧冻结条目和常驻不作为递归来源；禁止递归、禁止作为来源的作者设置继续生效。
递归候选仍须与原始查询相关；已检查并拒绝的条目本轮不复活。
编译器只消费最终候选，不自行进行新的关键词递归。

每次默认最多新增五条、3,000 字符，都是上限。中途条目与剧情共同计入窗口并随交流退出。
条目重复命中不移动，不重复抽签；离开请求才起算冷却，退出当轮不立即重新注入。
注入证据保存在快照中，包括来源、命中词、递归来源和可用分数；预算去留见上下文诊断。

## 模型和缓存

可选模型为 Qwen3 Embedding/Reranker 0.6B 或 4B，CUDA 推理由隔离进程运行。
需要 GPU 依赖时运行 setup.ps1 -LocalRetrieval，再通过设置下载和预热。
默认查询超时 1 秒、重排超时 1.5 秒；繁忙时跳过而不排队，失败终止工作进程，需重新预热。
模型路径与 API、下载和角色资源代理分别配置。代理地址默认为空，按直连处理；需要时在设置中显式填写。

索引身份包含实际内容、切片配置、模型配置及下载 revision。内容变化使派生缓存失效。
SQLite 保存索引与向量，记录当前集合引用；空闲清理先移除旧集合，再按容量淘汰可重建缓存。
模型权重单独管理，不随日志或索引自动删除，也不进入普通数据备份。

## 接口与验收

- GET/PUT /api/settings：Writer/Tracker 模型、检索、窗口和存储参数。
- GET /api/local-models：模型和任务状态；POST /api/local-models/{embedding|reranker}/{download|warmup}。
- POST /api/sessions/{id}/retrieval/rebuild：准备有效世界书索引，不执行查询。
- POST /api/sessions/{id}/preview：只读预览，不加载或推理神经模型，诊断注明不完整。

运行 tools/evaluate_retrieval.py；神经评估加 --neural --model-dir data/models，仅使用已下载权重。
评估经过最终上下文编译，包含多语言正例和无关查询，统计误注入、召回与延迟。
小型合成集合不代表任意社区卡的质量。
私有试玩回放工具 tools/replay_context.py 只输出汇总指标，源数据库和派生数据必须留在发行包之外。
