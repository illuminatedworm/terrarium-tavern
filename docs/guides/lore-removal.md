# 手动移除中途世界书注入

在剧情中的世界书注入列表点击“移除”，再确认即可移除该次注入。操作适用于已提交且当前空闲的会话；生成或审核期间，先完成或取消当前任务。请求失败时会显示通知，可重新尝试。

移除后，当前分支各快照中该次注入的标题、正文和检索证据被清除，界面与模型上下文随之更新。作用范围是所选条目在所选剧情位置的一次注入；其他条目、其他位置的注入和已有独立分支保持原样。

程序保留这次注入的内部定位与移除标记，刷新、重生成和新建分支都会继承。冷却仍从对应剧情自然退出窗口时开始，因此移除后到退出窗口前，该次注入继续占用原有的触发限制。

历史导航与分支操作见[阅读、编辑与分支](story-history.md)，注入和冷却规则见[世界书检索](retrieval.md#滚动与冷却)。
