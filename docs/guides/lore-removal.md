# 手动移除中途世界书注入

已提交的中途世界书条目可从剧情中的注入列表点击“移除”，经按钮附近的确认框确认后生效。运行中、待审核或显示未提交草稿时不能移除。取消确认不改动记录；请求失败显示通知，可重试。

移除会清除当前分支已有快照中该次注入的标题、内容和证据，只保留条目 ID、剧情锚点及内部移除状态。界面不展示内部记录，模型请求不包含内部记录或被移除的内容。其他条目及同条目在其他锚点的注入不受影响。已另存的分支会话保持独立。

手动移除不会重置或立即开始冷却。内部记录随原剧情锚点保留注入限制，锚点自然退出正文窗口后才按原有规则开始冷却。本操作使用会话版本校验、运行／待审核互斥和 SQLite 原子事务；刷新、重生成和新建分支继承移除状态。

# 引号显示

正文、正文编辑框和发送输入框把 U+201C / U+201D 显示为方向明显的角形标点。仅这两个字符使用项目自绘字形，其余文字沿用阅读字体设置。原文、复制内容、输入法、撤销及发送给模型的字符保持不变。静态字形位于 `web/assets/quote-marks.ttf`，可使用 `tools/build-quote-font.py` 和 fonttools 4.61.1 重新生成，不增加应用运行依赖。
