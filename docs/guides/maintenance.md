# 安装、备份与维护

本项目面向 Windows 本机使用。运行数据默认位于 `data/`；升级、排错和清理前应确认实际使用的数据目录。

## 安装与启动

准备 Python、Node.js 22+ 和 Git，在仓库或源码解压目录打开 PowerShell：

```powershell
.\setup.ps1
.\start.ps1
```

安装脚本使用 uv 管理项目所需的 Python 3.12 和锁定依赖，构建前端并下载 Chromium。普通使用无需 CUDA、PyTorch 或本地检索模型。启动后访问 `http://127.0.0.1:8000`，停止使用 `stop.ps1`。

安装脚本默认直连下载依赖。可用 `-Proxy` 指定 HTTP(S) 代理地址，或用空字符串禁用安装代理：

```powershell
.\setup.ps1 -Proxy ''
```

需要本地向量检索或重排时，使用 `setup.ps1 -LocalRetrieval` 安装额外依赖，再在设置中下载和预热模型。这条路线需要支持 CUDA 的 NVIDIA GPU，见[检索指南](retrieval.md#本地模型与索引)。

模型 API 代理由应用设置单独控制。API、模型下载和角色资源下载各有代理选项；安装脚本的环境不代替应用配置。

```powershell
.\start.ps1 -Port 8001
.\start.ps1 -Data 'D:\MyStories'
.\stop.ps1
```

## 备份、升级与回退

等待生成、审核及角色卡编辑任务结束，备份当前数据目录：

```powershell
.venv/Scripts/python.exe -m tavern --data data --backup backups/story.zip
```

备份包含数据库、角色资源、缓存依赖和运行日志，也包含编辑草稿、撤销记录、私人剧情与本地密钥；模型权重不在备份中。备份文件应按私有数据保存。目标文件已存在时不会覆盖。

恢复必须使用新的空目录，程序先验证清单与哈希，再写入内容：

```powershell
.venv/Scripts/python.exe -m tavern --data restored-data --restore backups/story.zip
.\start.ps1 -Data restored-data
```

升级时先保留完整备份，将新发行包解压到新程序目录，安装依赖，再用 `-Data` 指向原数据目录。程序打开 schema 1/2 数据库时，会备份并迁移到 schema 3；未知版本拒绝打开。需要回退旧程序时，从升级前的完整备份恢复到空目录，不能直接复用已经迁移的数据。迁移范围见[设置存储](../reference/settings-api.md#数据库与设置迁移)。

## 清理与资源保留

在“设置 → 通用 → 存储与维护”查看占用、可回收量和受保护量。清理预览使用已保存设置，修改限额后应等待保存成功再刷新预览。

| 数据 | 默认策略 | 保留边界 |
|---|---|---|
| 详细工作日志 | 最近 14 天、上限 512 MiB | 运行中、待审核及可重试失败回合受保护，可能暂时超额 |
| 剧情、分支、快照 | 持续保留 | 不作为旧日志清理 |
| 可重放上下文和工具 trace | 随所属会话／编辑工作区保留 | 与普通诊断日志分开 |
| 检索索引 | 上限 256 MiB | 先清无引用旧集合，再淘汰可重建缓存 |
| 本地模型权重 | 手动管理 | 不参与日志和索引清理 |
| 未保存编辑草稿与撤销历史 | 持续保留 | 由用户管理编辑对话 |

日志清理会将完整请求、流式片段和运行文件压缩为紧凑活动记录。数据库删行后文件不会立即缩小；手动清理可在空闲时收缩数据库。运行中的角色卡编辑任务阻止备份和清理。

资源由角色卡、副本、旧对话及编辑草稿共同保护。删除一个对象只回收失去全部引用的资源；删除会话会清除其正文、回合、工具轨迹和索引关联，独占索引才会被移除。

## 常见问题

| 现象 | 检查与操作 |
|---|---|
| 找不到 Python、npm 或 Git | 安装前置工具后重新打开终端 |
| 下载失败 | 检查代理是否监听、站点是否可达；保留数据目录 |
| 启动提示未构建 | 在项目根目录执行 `npm.cmd run build` |
| 端口占用 | 停止旧服务，或使用 `start.ps1 -Port 8001` |
| Half Agent 记忆失败 | 核对 Tracker 模型、密钥、代理及预算；修复后手动整理，见[窗口与记忆](history-maintenance-settings.md) |
| Full Agent 无法继续 | 检查工具开关、调用额度和 handoff，见[失败恢复](full-agent.md#失败恢复与排查) |
| 预计输入很大 | 区分本地估算与上次实际用量，检查[内容占比](token-counting.md) |
| 世界书未注入或本地模型不可用 | 按[检索排查顺序](retrieval.md#排查未命中与误注入)检查，不以补满候选数量作为目标 |
| 详细事件已过期 | 查看紧凑记录；剧情和恢复所需状态仍保留 |

提示词配置见[设置指南](settings.md#提示词与输出格式)，开发启动与验证见[验证与发行](../development/validation.md)。
