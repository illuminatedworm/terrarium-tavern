# 安装、备份与长期维护

## Windows 安装

准备 Python（安装器可取得项目需要的 3.12）、Node.js 22+ 和 Git。在解压目录运行 setup.ps1，再运行 start.ps1。
setup.ps1 默认直连；可用 -Proxy 显式指定安装代理。
普通使用不需要 CUDA、PyTorch 或本地检索模型。需要时使用 -LocalRetrieval。
模型 API 的代理在应用设置中单独配置。

遇到 Python/npm 命令不存在，先安装前置工具并重新打开终端。
遇到下载失败，检查代理是否监听以及对应站点能否访问；不要删除数据目录排错。
启动提示未构建时运行 npm.cmd run build。端口占用时使用 start.ps1 -Port 8001，或先 stop.ps1。

## 备份与升级

暂停生成后执行：

```powershell
.venv/Scripts/python.exe -m tavern --data data --backup backups/story.zip
.venv/Scripts/python.exe -m tavern --data restored-data --restore backups/story.zip
.\start.ps1 -Data restored-data
```

备份包括数据库、角色资源、依赖及运行日志，包含私人内容与本地密钥；不包含大型模型权重。
恢复先检查清单和哈希，只写入新的空目录。备份目标已存在时不会覆盖。
升级前备份，解压新发行包到新目录，安装依赖，再通过 -Data 指向原数据目录。
程序只打开所支持的数据库格式；更换程序前保留独立备份。

## 自动清理

设置 → 存储与维护显示占用、可回收量和受保护量。
详细日志默认最近 14 天且上限 512 MiB；完整请求、流式片段、重复正文和运行文件可被压缩为紧凑活动记录。
正在运行、待审核以及仍可重试的失败回合受保护，可能暂时超过限额。
剧情消息、分支和快照始终保留。索引默认上限 256 MiB，先清理无引用旧集合，再淘汰可重建缓存。
模型权重不参与自动清理。数据库文件不会因删行立即缩小，手动清理可在空闲时收缩文件。
清理预览使用已保存设置；更改限额后先保存，再刷新预览。

## 常见情况

- 记忆整理失败：核对后台 Tracker 模型名称、Key、代理和容量；修复后点击重新整理。无需裁剪时正文可继续。
- 预览数值很大：当前显示本地估算 tokens，与“上次实际输入 tokens”不同；检查占比和注入诊断。
- 没有世界书条目：候选数是上限，零命中可正常发生；查看主体证据、重排阈值、时间线和预算。
- 本地模型不可用：等待下载完成并手动预热；查询失败不自动加载或放宽过滤。
- 详细记录已过期：紧凑任务记录仍在，剧情和快照不受影响。


## 系统提示词与记忆标记

“设置 → 系统提示词”开放 11 项应用提示词：RP、记忆整理、检索线索、检索输出协议、设定维护、对话偏好引导词、重新生成引导词、本地检索任务、Reranker 判断、接口检查引导词及标记。每项可独立恢复默认值，修改后保存设置生效。默认值由后端统一提供；自定义文本按原样保存。

记忆由 `snapshot.memory_document` 保存分类条目及来源信息；上下文编译通过 `render_memory` 生成自然语言视图，以 `<tavern_memory>…</tavern_memory>` 包裹并按配方的 `memory` 块发送。内部来源 ID 不直接发送给模型。无记忆时省略空块。

检索解析使用 `<tavern_retrieval>` 标签；记忆整理保留 JSON 字段与来源引用；Reranker 使用 yes/no token 概率评分；接口检查识别 `TAVERN_MID_42`。编辑相应提示词时保留这些格式约定。

## 编辑工作区

独立编辑草稿、撤销版本与编辑对话属于用户数据，备份包含这些内容。运行中的编辑任务阻止备份和清理。未保存草稿不自动清除；已保存工作区的详细事件遵循日志保留期与容量上限。草稿、旧对话与副本共同保护引用资源，删除原卡不会损坏它们。
