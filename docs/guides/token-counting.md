# Token、字符与字节

游玩、制卡 agent 和参谋 agent 显示“上次请求实测输入”，只使用接口真实返回的计数，不额外发计数请求。它描述的是发送那一刻的输入，**不是当前本地上下文的长度**：之后的回复、工具结果、新输入或图片，要等下一次请求才计量。没有有效计数时显示“暂无实测”，而不是零或本地估值。

## 计数口径

| 项目 | 单位 | 计数方式 |
|---|---|---|
| 模型上下文窗口、输出预算 | tokens | 按实际接入配置 |
| 窗口压力与自动整理 | tokens | 对应用途的上次有效实测输入 |
| 剧情模型交接、笔记和规划限额 | tokens | 剧情模型选定的本地分词器 |
| 实际输入、输出、思考、缓存 | tokens | 按接口语义读取；缺失项保持未知 |
| 检索查询与线索范围 | 字符 | Unicode 字符，包含空格与换行 |
| Embedding／Reranker 切片 | tokens | 对应本地模型的 tokenizer |
| BM25 切片 | 词元 | 中文、日文、英文分词及二元组 |
| 日志与存储大小 | 字节、KiB、MiB | 磁盘或 UTF-8 大小 |

本地分词继续用于独立文本限额、记忆分批和检索，不用于预测当前上下文总量。随包提供 tiktoken 的 `o200k_base`、`cl100k_base`；未知模型使用参考分词器。检索切片用于定位资料，剧情动态条目的预览按 Unicode 字符计数，按短编号读取时返回全文。

## 实测快照与窗口行为

请求观测按会话／工作区和用途隔离，绑定模型、接入来源、工具定义、思考设置及窗口代际。用途随请求显式传递。请求指纹只用于匹配内容，不计算增量 tokens，也不保存第二份提示词正文；制卡与游玩图片以稳定资源引用匹配，刷新统计时不读取图片二进制。

游玩模型看图的接口实测包含图片输入；本地分词预测排除图片编码并注明含图片的块。独立媒体生成不并入剧情上下文计数，首版使用图片张数、配音片段数和字符总量控制自动调用，不将这些数量换算成 tokens 或账单金额。

**匹配状态**

- `exact`：内容相同。
- `appended`：在完整前缀之后追加了内容；数值仍是上次实测。
- `changed`：内容被改写、删除或重排；旧值仅供历史参考，不触发自动整理。

换窗、compact、模型或来源变化后，等待新的实测。签名、密文、图片和原生回放保持原样，不按编码长度猜算占用，也不按模型名猜测思考的保留量。

**请求没有返回计数时**

- 最新请求完成但缺少有效计数：转为未知，不回头使用更早的数据。
- 请求被取消、失败（含限流）或因重启中断：这次请求说明不了输入大小，于是保留请求前最后一份已完成的记录（实测值或超限拒绝）；它仍须通过来源、代际和内容前缀匹配，才能作为窗口依据。没有这样的记录时转为未知。界面单独标出最新尝试的状态（“最近请求失败／已取消／因重启中断”），并把沿用的数字称为“此前请求实测输入”。
- 服务商明确以上下文超限拒绝：同样没有数值，界面标为“上次请求超出窗口”；如果之后的尝试又失败，则标为“此前请求超出窗口”并显示最新的失败状态。只要内容前缀和实际发送的输出额度仍然匹配，这一拒绝可以驱动一次自动整理或窗口退出。调整输出额度后不再沿用旧的拒绝结论（成功请求的实测值仍按原规则匹配）；SIWC 的输出额度由服务端决定。

请求顺序号保证迟到的响应不会覆盖新请求。实际发生的用量独立于剧情提交保存：取消或拒绝审核不会抹去用量，但未提交的内容也不会成为已提交剧情的窗口依据。

实测快照当前为第 3 版，额外保存拒绝时实际发送的输出额度和最新尝试状态；旧格式快照不参与判断，等待下一次实际请求取得新观测，剧情与窗口设置不变。

| 机制 | 实测驱动规则 |
|---|---|
| 剧情模型、制卡 agent | 达到提醒比例时提示；实测输入达到窗口上限时要求换窗。提醒本身不增加实测值 |
| 自动 compact／参谋咨询整理 | 保留原开关、阈值和近期交流保护；成功后等待新实测，不用同一旧水位循环整理 |
| 无有效实测 | 不按 tokens 自动整理，仍可手动整理；大输入或大工具结果可能直接被服务商拒绝，进度保留。明确的超限拒绝在下次发送前触发一次自动整理或窗口退出；剧情模型与制卡 agent 的换窗仍由模型调用，请求过大时需手动处理 |
| 显式整理 | 使用完整可整理交流；只有明确的服务端上下文超限才按交流边界二分，单次交流仍超限则停止，不截断内容 |

已有云端压缩状态失效本身就是重建依据，不需要新的实测：自动压缩开启时，在下一次实际模型请求（包括同回合工具续答）前重建全部已完成交流。普通动态状态通过追加更新，固定资料按最终展开文本校验，无关的变量变化或相同的展开结果不触发重建。

切换上下文模式不会仅因本地原文很长而隐式发起整理请求。独立文本写入限额见[文本完整性](../design/text-integrity.md)。

## 接口提供了什么

- Gemini：`promptTokenCount` 是输入（已含缓存读取），`candidatesTokenCount` 是候选输出，`thoughtsTokenCount` 是额外思考，`totalTokenCount` 保留原始总用量；模态分项、选中候选和服务端工具输入按返回提供。生成的思考不能当作下一次输入占用。
- Responses／ChatGPT：保留输入、输出、输出内的推理分项及实际返回的 `reasoning.context`。输出可能包含不可见结构，不能把“输入＋输出”称为当前上下文长度。
- Anthropic：输入为 `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`，任一桶缺失即未知。有 `usage.iterations` 时选最后一个 `message` 采样，排除 `compaction`、参谋子采样和累计量；输出仍是整个响应的用量。清除与输入变换只展示接口已报告的摘要。
- Chat Completions：读取实际输入、输出及推理分项；缺字段保持未知。

输出是否包含思考按协议标注，不重复相加，也不把相减的结果称为正文长度；原始总用量缺失时保持未知。不会为了获取可选字段而启用 beta、更改 API 版本或修改模型请求。字段映射及来源见[模型接入参考](../reference/model-api.md#原生回复与用量)。

## 累计缓存命中率

缓存命中率按统计范围内的**累计缓存读取 tokens ÷ 累计输入 tokens**计算，输入包含缓存命中部分。输入框旁标为“累计缓存命中率”，悬停或键盘聚焦可查看累计缓存读取、未命中与输入合计 tokens。制卡对话从开始至今累计，游玩按当前分支的一段连续游玩累计。

官方 API 若返回失败／不完整响应及 usage，实际消耗单独写入“失败请求用量”，保留原始计数并纳入累计消耗；没有返回的计数保持未知。失败数据不成为有效窗口实测，不触发正文或工具提交。资料调查者的累计消耗同样包含接口已返回的失败用量。

游玩回合与制卡任务运行期间，缓存命中率保留运行前最后一次完整统计。游玩时在其他标签页打开同一故事的预览，也会读到这份统计。任务结束（含停止或失败）后重新读取累计用量，等待刷新或刷新失败时保留已显示的数值。结束后的统计缺少接口计数时显示“暂无”。

游玩累计正文、工具续答和上下文维护的接口用量。从上一项游玩任务结束到下一项开始，空闲满 30 分钟时重新起算。模型工作与工具续答期间不计算空闲，等待人工审核计入空闲。重启前后的空闲时间连续计算；运行中断时使用最后一次保存的活动时间。

实际模型或接入来源变更、本地换窗或云端 compact 生效时开新段。全局设置的保存、撤回或导入只重置实际连接发生变化的故事，切回原模型也从新段开始。回合内从第一次使用新窗口的请求起算，生成新检查点的整理请求归入此前的段。失败、取消或拒绝审核后回到旧窗口时，恢复此前的段并保留逐次用量记录。同一窗口内的重生成及未提交请求已经返回的用量照常累计。

游玩空闲满 30 分钟或新段尚未取得用量时显示“暂无”。已有游玩对话从功能启用后的首次请求起算，新分支独立累计。统计只使用接口真实返回的数据。统计范围内的请求缺少输入或缓存读取计数、或累计输入为零时，显示“暂无”。接口明确返回零缓存读取且输入大于零时显示 0%。逐次用量随会话保存，清理详细日志保留累计值。

## 查看实测与完整预览

上下文预览保留完整消息、来源分组、消息／条目／图片数量；接口实测分项单列展示。打开游玩上下文预览或参谋 agent 预览时，另附“本地分词预测”：逐块、分组合计、分类占比和请求总量，标注所用分词器，仅用于比较各块相对大小。密文与图片不计入，云端压缩状态显示为不计入。它只在生成这两个预览时计算，不写入 `context_usage`，也不参与请求编译和任何窗口、整理、警告或分批判断；输入框旁的统计不计算它。制卡 agent 暂不提供该参考。预览使用词法检索，正式发送还可能运行已启用的神经检索，因此世界书命中可能变化。

`context_usage` 的字段：

- `tokens`：可空的实测输入；`source` 只有 `provider` 和 `unavailable`。
- `coverage`、`added_blocks`、`pending`、`observed_at`、`unavailable_reason`：说明匹配和时间边界。
- `last_attempt`：单独记录最新尝试的 `pending`、`completed`、`request_failed`、`request_cancelled`、`interrupted` 或 `context_overflow` 状态；此前观测的时间不能当作这次尝试的完成时间。
- `input_scope`：区分 `request` 与 `last_iteration`。
- 可空分项：`output_tokens`、`thinking_tokens`、`reported_total_tokens`、缓存和模态明细；`output_includes_thinking` 说明包含关系。
- `reasoning_context`、`context_edits`、`input_transformations`、`compacted`：只说明接口已返回的行为，不据此重算当前占用。

预览、统计接口和 SSE 不再返回旧的 `estimated_tokens`、`token_counting`、`budget_sources` 和 trace 中的 token 字段，也没有 `calibrated`／`local` 兜底来源；游玩和参谋 agent 的上下文预览仍可返回独立的 `local_estimate` 与 `trace.local_tokens`，用于本地分词预测。`GET /api/sessions/{sid}/advisor/stats` 返回当前配置对应的快照与 `context_limit`。SSE 传递绝对快照，重连不累加；配置改变或请求结束后重新核对，旧异步结果不能覆盖新会话。

游玩预览和制卡统计的 `cache_usage` 返回各自统计范围内的累计 `prompt_tokens` 与 `cached_tokens`。没有记录为 `null`，某项不完整时该项为 `null`。游玩预览另返回 `cache_usage_expires_at`，以 Unix 秒表示该段空闲到期时间。任务运行中或统计已不可用时该时间为 `null`。`usage` 仍表示最近一次响应。

## 实现入口

模型传输中计量的开始、完成与失败，各自作为 SQLite 短事务在工作线程中写入，调用方异步等待，不在事件循环中等待写锁；取消时先等已启动的事务收尾，再清理请求状态，已收到的用量保留；数据库持续不可写时明确报错。

接口观测位于 [core/context_usage.py](../../src/tavern/core/context_usage.py)，真实字段映射位于 [core/usage.py](../../src/tavern/core/usage.py)，独立文本分词位于 [core/tokens.py](../../src/tavern/core/tokens.py)。词表与校验值见 [manifest.json](../../src/tavern/tokenizer_data/manifest.json)；更新工具为 [prepare_tokenizers.py](../../tools/prepare_tokenizers.py)。
