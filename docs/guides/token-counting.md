# Token、字符与字节

游玩、制卡 agent 和参谋 agent 显示“上次请求实测输入”，只使用接口真实返回的计数，不增加计数请求。它描述发送那一刻的输入，**不是当前本地上下文长度**。回复、工具结果、新输入或图片的后续变化等待下一次请求计量；缺少有效计数显示“暂无实测”，不显示零或本地估值。

## 计数口径

| 项目 | 单位 | 计数方式 |
|---|---|---|
| 模型上下文窗口、输出预算 | tokens | 按实际接入配置 |
| 窗口压力与自动整理 | tokens | 对应用途的上次有效实测输入 |
| 配方块提示、Tracker 分批与活跃记忆 | tokens | 对应角色选定的本地分词器 |
| Full Agent 交接、笔记和规划限额 | tokens | Full Agent 选定的本地分词器 |
| 实际输入、输出、思考、缓存 | tokens | 按接口语义读取；缺失项保持未知 |
| 检索查询与线索范围 | 字符 | Unicode 字符，包含空格与换行 |
| Embedding／Reranker 切片 | tokens | 对应本地模型的 tokenizer |
| BM25 切片 | 词元 | 中文、日文、英文分词及二元组 |
| 日志与存储大小 | 字节、KiB、MiB | 磁盘或 UTF-8 大小 |

本地分词继续用于独立文本限额、记忆分批和检索，不用于预测当前上下文总量。随包提供 tiktoken 的 `o200k_base`、`cl100k_base`；未知模型使用参考分词器。检索切片用于定位资料，选中的世界书条目仍完整注入。

## 实测快照与窗口行为

请求观测按会话／工作区、用途隔离，绑定模型、接入来源、工具定义、思考设置及窗口代际。用途随请求显式传递，脚本嵌套调用不会改写 Writer 通道。请求指纹只用于匹配内容，不计算增量 tokens，不保存第二份提示词正文；制卡图片以不可替换的附件引用匹配，统计刷新不读取图片二进制。

相同内容标为 `exact`；完整前缀之后追加内容标为 `appended`，数值仍保持上次实测；改写、删除或重排标为 `changed`，旧值仅供历史参考，不触发自动整理。换窗、compact、模型或来源变化后等待新实测。签名、密文、图片及原生回放保持原样，不通过编码长度猜算占用，也不按模型名猜测思考保留量。

请求中可保留明确标注的此前快照。最新请求完成但缺少有效计数时转为未知，不回捞更早数据。请求被取消、失败（含限流）或因重启中断时不能说明输入大小，保留请求前最后一份已完成记录（实测或超限拒绝），仍须通过来源、代际和内容前缀匹配才能作为窗口依据；没有这样的记录时转为未知。最新尝试状态单独保留：界面标注“最近请求失败／已取消／因重启中断”，并把被沿用的数字称为“此前请求实测输入”，不冒充最新尝试的结果。服务商明确以上下文超限拒绝时同样没有数值，界面标为“上次请求超出窗口”；若后续尝试失败，则标为“此前请求超出窗口”并显示最新失败状态。内容前缀与实际发送的输出额度仍匹配时可驱动一次自动整理或窗口退出。调整输出额度后不复用旧拒绝结论，成功请求的输入实测仍可按原匹配规则使用；官方订阅路由没有可配置的请求输出额度。请求顺序号阻止迟到响应覆盖新请求。实际发生的用量独立于剧情提交保存，取消或拒绝审核不会抹去用量，也不会让未提交内容成为当前已提交剧情的窗口依据。

实测快照格式升级为第 3 版，同时保存拒绝时实际发送的输出额度和最新尝试状态；旧格式快照不再参与判断，等待下一次实际请求取得新观测，剧情与窗口设置不变。

模型传输中的计量开始、完成与失败写入各自作为完整 SQLite 短事务在工作线程执行，调用方异步等待，不在事件循环中等待写锁。取消时先等待已启动事务收尾，再清理请求状态；已收到的实际用量仍保留。数据库持续不可写时仍明确报错，不静默丢弃计量记录。只读查询和其他业务存储路径保持原有方式。

| 机制 | 实测驱动规则 |
|---|---|
| Full Agent、制卡 agent | 达到提醒比例时提示；实测输入达到窗口上限时要求换窗。提醒本身不增加实测值 |
| Half Agent 本地窗口 | 可用输入容量扣除输出预算及 2048 tokens 余量，与日常预算取较小值；超过压力比例只退出一个完整批次。消息 cap 独立生效 |
| 自动 compact／参谋咨询整理 | 保留原开关、阈值和近期交流保护；成功后等待新实测，不用同一旧水位循环整理 |
| 无有效实测 | 不按 tokens 自动整理，仍可手动整理；大输入或大工具结果可能直接被服务商拒绝，进度保留。明确的超限拒绝在下次发送前触发一次自动整理或窗口退出；Full Agent 与制卡 agent 的换窗仍由模型调用，请求过大时需手动处理 |
| 显式整理 | 使用完整可整理交流；只有明确的服务端上下文超限才按交流边界二分，单次交流仍超限则停止，不截断内容 |

已有云端压缩状态失效时，自动压缩开启则在下一次实际模型请求前重建全部已完成交流，包括同回合工具续答；该依据不依赖 token 估算或新实测。普通动态状态通过追加更新，固定资料按最终展开文本校验；无关变量变化或相同展开结果不触发重建。

切换上下文模式不会仅因本地原文很长而隐式发起整理请求。Half Agent 退出前仍须满足记忆覆盖，保留最近两次完整交流和当前输入。独立文本写入限额见[文本完整性](../design/text-integrity.md)。

## 接口提供了什么

- Gemini：`promptTokenCount` 是输入（已含缓存读取），`candidatesTokenCount` 是候选输出，`thoughtsTokenCount` 是额外思考，`totalTokenCount` 保留原始总用量；模态分项、选中候选和服务端工具输入按返回提供。生成的思考不能当作下一次输入占用。
- Responses／ChatGPT：保留输入、输出、输出内的推理分项及实际返回的 `reasoning.context`。输出可能包含不可见结构，不能把“输入＋输出”称为当前上下文长度。
- Anthropic：输入为 `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`，任一桶缺失即未知。有 `usage.iterations` 时选最后一个 `message` 采样，排除 `compaction`、参谋子采样和累计量；输出仍是整个响应的用量。清除与输入变换只展示接口已报告的摘要。
- Chat Completions：读取实际输入、输出及推理分项；缺字段保持未知，不替中转服务补造语义。

输出与思考是否包含关系按协议标注，不重复相加，不把相减结果称为实测正文长度；原始总用量缺失时不补造。不为获取可选字段自动启用 beta、改 API 版本或修改模型请求。字段映射及来源见[模型接入参考](../reference/model-api.md#原生回复与用量)。

## 累计缓存命中率

所有缓存命中率均按当前会话从开始至今的**累计缓存读取 tokens ÷ 累计输入 tokens**计算，输入包含缓存命中部分，不是对逐次百分比取平均。输入框旁明确标为“累计缓存命中率”，悬停或键盘聚焦会弹出明细卡片，列出累计缓存读取、未命中与输入合计 tokens 及命中比例条，便于核对首请求和后续调用对累计值的影响。

游玩回合与制卡任务运行期间，缓存命中率保留运行前最后一次完整统计；任务结束（含停止或失败）后重新读取累计用量。实测快照按请求完成结果更新，其加载或失败不会清空已显示的缓存命中率；若结束后的统计确实缺少接口计数，则如实显示“暂无”。

游玩会话累计正文、工具续答、Tracker、变量分析和上下文维护的接口用量；制卡对话独立累计，不与游玩或参谋 agent 咨询混算。重生成及未提交请求已经返回的用量也计入，切换模型不清零；新分支只累计该分支实际发起的请求，不重复计入继承剧情的原分支请求。

累计缓存统计只使用接口真实返回的数据。没有请求、任一请求缺少输入或缓存读取计数、累计输入为零，或旧逐次用量记录不完整时，显示“缺失”；不使用本地估算、内部计费补零或最近一次响应代替。接口明确返回零缓存读取且输入大于零时显示 0%。逐次用量随会话保存，重新打开页面和清理详细日志不会重置累计值。

## 查看实测与完整预览

上下文预览保留完整消息、来源分组、消息／条目／图片数量；接口实测分项单列展示。打开游玩上下文预览或参谋 agent 预览时，另附“本地分词预测”：逐块、分组合计、分类占比和请求总量，标注所用分词器，仅用于比较各块相对大小。密文与图片不计入，云端压缩状态显示为不计入。它只在生成这两个预览时计算，不写入 `context_usage`，不进入每轮请求编译，也不参与压力、换窗、整理、警告或分批；输入框旁的统计刷新不计算它。制卡 agent 暂不提供该参考。预览使用词法检索，正式发送还可能运行已启用的神经检索，因此世界书命中可能变化。

`context_usage.tokens` 为可空的实测输入，`source` 只有 `provider` 和 `unavailable`。`coverage`、`added_blocks`、`pending`、`observed_at`、`unavailable_reason` 说明匹配和时间边界；`last_attempt` 单独记录最新尝试的 `pending`、`completed`、`request_failed`、`request_cancelled`、`interrupted` 或 `context_overflow` 状态，不能把此前观测的时间当成这次尝试的完成时间；`input_scope` 区分 `request` 与 `last_iteration`。可空分项为 `output_tokens`、`thinking_tokens`、`reported_total_tokens`、缓存和模态明细；`output_includes_thinking` 说明包含关系。`reasoning_context`、`context_edits`、`input_transformations`、`compacted` 仅说明接口已返回的行为，不据此重算当前占用。

预览、统计接口及 SSE 不再返回 `estimated_tokens`、`token_counting`、`budget_sources`、trace 的 token 字段，也没有 `calibrated`／`local` 兜底。`GET /api/sessions/{sid}/advisor/stats` 返回当前配置对应的快照与 `context_limit`。SSE 传递绝对快照，重连不累加；配置改变或请求结束后重新核对，旧异步结果不能覆盖新会话。

游玩预览和制卡统计的 `cache_usage` 返回会话累计 `prompt_tokens` 与 `cached_tokens`；没有记录为 `null`，某项不完整时该项为 `null`。`usage` 仍表示最近一次响应，不参与累计缓存命中率计算。
