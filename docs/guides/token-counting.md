# Token、字符与字节

界面的预计输入用于判断上下文占用，实际输入输出取自服务商返回。费用以实际用量和账单核对，窗口压力以本地编译结果计算。

## 计数口径

| 项目 | 单位 | 计数方式 |
|---|---|---|
| 模型上下文窗口、输出预算 | tokens | 按实际接入配置 |
| Half Agent 日常预算、历史预算、配方提示阈值 | tokens | Writer 模型所选的 BPE 分词器 |
| Tracker 分批、输出与活跃记忆 | tokens | Tracker 模型所选的分词器 |
| Full Agent 窗口、交接笔记、长期笔记和规划 | tokens | Full Agent 模型所选的分词器 |
| 模型请求估算 | tokens | 消息、封装、工具定义、工具结果及原生续答 |
| 实际输入、输出和缓存用量 | tokens | 按接口归一化，另行保留原始 usage |
| 检索查询与线索范围 | 字符 | Unicode 字符，包含空格与换行 |
| Embedding／Reranker 切片 | tokens | 对应本地模型的 tokenizer |
| BM25 切片 | 词元 | 中文、日文、英文分词及二元组 |
| 日志与存储大小 | 字节、KiB、MiB | 磁盘或 UTF-8 大小 |

检索切片用于定位资料，选中的世界书条目仍完整注入。

## 估算精度与预算行为

本地使用 tiktoken，随包提供 `o200k_base` 和 `cl100k_base` 词表。分词器可自动匹配或手动指定；未知模型使用 `o200k_base` 作为参考。

文本计数对应所选分词器，消息封装、工具和原生推理块采用本地估算。服务商的分词规则与封装方式可能产生差异。云端 compact 后，本地只计可见文本，加密状态的占用以服务商返回为准。

Writer、Tracker、Full Agent、制卡 agent 与参谋 agent 共用请求计数层，将历史思考字段计入上下文，按原始 Unicode 文本估算，不把 JSON 的 `\uXXXX` 转义串作为思考正文计数。原生回复附件与其旁存的思考字段只计一次，避免漏算、重复计数或中文转义造成窗口压力误判。加密内容不按密文长度推算模型占用。

游玩和制卡输入框显示“当前上下文 tokens / 上下文窗口上限”，悬停可查看口径。上下文详情提供上次实际输入；所有缓存命中率均按当前会话从开始至今的**累计缓存读取 tokens ÷ 累计输入 tokens**计算，输入包含缓存命中部分，不是对逐次百分比取平均。输入框旁明确标为“累计缓存命中率”，悬停或键盘聚焦会弹出明细卡片，列出累计缓存读取、未命中与输入合计 tokens 及命中比例条，便于核对首请求和后续调用对累计值的影响。

游玩回合与制卡任务运行期间，缓存命中率保留运行前最后一次完整统计；任务结束（含停止或失败）后重新读取累计用量。实时上下文估算继续更新，其加载或失败不会清空已显示的缓存命中率；若结束后的统计确实缺少接口计数，则如实显示“暂无”。

游玩会话累计正文、工具续答、Tracker、变量分析和上下文维护的接口用量；制卡对话独立累计，不与游玩或参谋 agent 咨询混算。重生成及未提交请求已经返回的用量也计入，切换模型不清零；新分支只累计该分支实际发起的请求，不重复计入继承剧情的原分支请求。

统计只使用接口真实返回的数据。没有请求、任一请求缺少输入或缓存读取计数、累计输入为零，或旧逐次用量记录不完整时，显示“缺失”；不使用本地估算、内部计费补零或最近一次响应代替。接口明确返回零缓存读取且输入大于零时显示 0%。逐次用量随会话保存，重新打开页面和清理详细日志不会重置累计值。

| 预算用途 | 处理方式 |
|---|---|
| Half Agent 本地窗口 | 可用输入容量扣除输出预算和 2048 tokens 余量，再计算窗口压力 |
| Full Agent 强制换窗 | 当前上下文达到窗口上限时触发，按输入本身计数 |
| 通用请求诊断 | 同时检查输入、输出额度和余量，超量时提示 |
| 内部文本发送 | 已选角色卡、剧情、记忆和工具原文完整发送，超量请求由服务商接受或拒绝 |
| 外部网页与文件 | 按各自读取协议返回有长度限制的摘要或片段 |

记忆条目数量、交接笔记和长期笔记长度另有写入校验，见[文本完整性](../design/text-integrity.md)。

## 查看占比

上下文预览按来源展示剧情、设定、记忆和请求开销。预览使用词法检索；正式发送还可能运行已启用的神经检索，因此世界书命中可能变化。

API 中，`estimated_tokens` 是包含封装的总估算，`token_counting` 说明分词器口径，`budget_sources` 给出来源分组；trace 的 `content_tokens` 统计正文。缺失的服务商用量保持未知，字段映射见[模型接入参考](../reference/model-api.md#原生回复与用量)。

游玩预览和制卡统计接口的 `cache_usage` 返回会话累计 `prompt_tokens` 与 `cached_tokens`；没有记录时为 `null`，某项累计不完整时对应字段为 `null`。原有 `usage` 仍表示最近一次响应，供“上次实际输入”等单次用量展示使用，不参与缓存命中率计算。制卡 SSE 的 `context_stats` 同样返回累计快照，重连回放不会重复累加。
