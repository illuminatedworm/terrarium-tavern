# 阅读、编辑与分支

本指南适用于 Half Agent 和 Full Agent。剧情原文、当前模型窗口和界面显示范围各有用途：翻阅旧消息不会让它们重新进入模型请求，换窗也不会删除原文。

## 定位历史

对话刻度栏覆盖当前分支的完整历史。白色表示阅读位置，黄色表示当前计划缓存断点。可点击或拖动刻度定位，也可使用方向键及 Home/End；引用原文和“定位断点”使用同一消息定位入口。

长对话只渲染可见区域附近的消息，滚动时加载其他位置。这不改变模型上下文或已保存剧情。缓存标记的含义见[提示缓存](prompt-cache.md)，Full Agent 的工具过程见[使用指南](full-agent.md)。

## 编辑与重生成

两种模式都允许直接编辑当前分支最后一轮的用户消息与 AI 回复；未提交输入仍可修改后重试。编辑区沿用正文排版并随原文自动伸缩，Markdown 和 HTML 仍编辑原文。编辑原文不自动重演后续变量。需要从早期事件改变故事时，应先建立分支，或选择合适的回复版本。

单击编辑后，点击“保存修改”或按 Ctrl+Enter，先选择“提醒 AI”或“不提醒 AI”，再保存；关闭询问可继续编辑。按住编辑按钮 300ms 会展开“修改后，提醒 AI”和“不提醒 AI”，移入选项后松开即选择并开始编辑，本次保存不再询问。也可以松开在原按钮上保留菜单后点击选项，或用 Shift+F10 打开菜单。选择只用于本次编辑，未修改内容直接退出；Esc 取消。待重试输入直接保存，不显示历史修改提醒询问。

“提醒 AI”不会在保存时调用模型，而是在下一次正常发送或重新生成时向 Writer / Full Agent，以及本轮实际运行的 Tracker 提供当前修订文本或有效短编号。成功提交本轮后消费提醒；预览、失败、取消和拒绝审核保留提醒。重复编辑同一消息采用最新选择，“不提醒 AI”撤回该消息未发送的提醒。编辑接口的 `notify_ai` 默认 `false`。

重生成复用对应用户输入和回合前快照，不新增一条用户台词，也不增加已完成剧情轮数。成功的新回复拥有自己的状态快照；切换回复版本时恢复对应状态和工具过程。

展开“重新生成”后，可勾选“带上原 AI 回复作为重写参考”，默认关闭。开启后，将当前待重写回复的完整模型可见正文作为本轮参考提供给 Writer / Full Agent，并结合补充要求改写；它不作为已发生剧情，不继承原回复写入的 handoff、长期笔记、变量或工具过程。重生成仍从回合前快照开始，参考不会进入后续普通回合。失败后重试会恢复这项选择；改变选择时 Full Agent 重新开始本轮。接口字段 `regenerate_include_reply` 默认 `false`。

重生成选项在输入框上方浮动展开，不改变正文区域高度、消息阅读导航按钮的位置或对话刻度栏的尺寸。再次点击“重新生成”可收起，选项内按 Esc 收起并返回按钮。

编辑原文后的记忆处理不同：

| 模式 | 处理 |
|---|---|
| Half Agent | 保留已有记忆并提示来源改变；手动重建才重新核对全部可见原文 |
| Full Agent | handoff 和长期笔记保留真实的来源过时状态；旧工具续答退出活动窗口 |

是否主动提醒模型由本次编辑选择决定，来源校验和记忆保护始终生效；“不提醒 AI”不代表来源重新有效，也不触发记忆重建。

变量需要通过变量界面显式修订，或从合适的历史进度重新生成。修改文字本身不等于执行原剧情中描述的变量变化。

## 创建独立分支

从选定的 AI 回复创建分支，会复制该回复的祖先消息及状态，继承运行模式，并映射记忆来源和世界书锚点。新分支是独立会话，删除源会话不影响它。

修改书架角色卡只影响以后创建的故事，已有故事使用自己的角色资料。需要改变当前故事的设定时，使用对话内编辑入口或授权维护；角色卡操作见[编辑指南](card-editor.md)。

## 世界书与文字显示

中途世界书条目可从剧情中的注入列表移除，具体生命周期见[移除说明](lore-removal.md)。

正文、正文编辑框和发送输入框将 U+201C/U+201D 引号显示为方向明显的角形字形。复制、编辑和发送给模型的字符仍是原字符；显示字体不会替换存档文本。需要调整其实现时，见[前端资源](../development/structure.md#前端与生成资源)。
