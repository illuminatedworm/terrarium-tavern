# 阅读、编辑与分支

Half Agent 和 Full Agent 都保存完整剧情，并分别管理模型窗口和页面显示范围。历史阅读用于浏览存档，模型请求按当前上下文设置编排。

## 定位历史

右侧对话刻度栏覆盖当前分支：白色三角表示阅读位置，黄色标记表示计划缓存断点，圆环表示预览位置。点击或拖动可快速定位；长对话先显示全局概览，再展开附近五个位置供精确选择。

悬停、点击或聚焦刻度可查看轮号和正文摘要，滚轮及“上一轮／下一轮”切换预览，点击条目跳转。刻度获得焦点后，方向键逐轮跳转，Home／End 跳到首尾，Enter 确认预览，Esc 关闭。触屏可先点击刻度，再使用预览按钮。

每条已提交消息在名称旁以低对比小字显示消息编号：H52 表示当前分支第 52 条消息，开场白为 H1。Half Agent 记忆来源、Full Agent 笔记来源和模型引用的原文都使用同一编号；编号按分支位置计算，其他分支同一位置是各自的消息，尚未提交的输入和回复不显示编号。

页面按需渲染阅读位置附近的消息，其余历史继续保存在存档中。缓存标记见[提示缓存](prompt-cache.md)，工具过程见 [Full Agent 使用指南](full-agent.md)。

## 编辑与重生成

两种模式都只允许修改当前分支最新一轮的用户输入。AI 回复、开场白及更早输入不可编辑；要从更早进度改变故事，先创建分支或切换轮次版本。编辑框沿用正文排版，Markdown 和 HTML 使用原文编辑。

| 操作 | 方式 |
|---|---|
| 修改并重试 | 点击最新用户输入的编辑按钮，修改后点击“修改并重试”或按 Ctrl+Enter，立即重新生成本轮 |
| 放弃修改 | 按 Esc，或点击“取消”；原输入保持不变 |
| 修改失败或取消的输入 | 在“待提交输入”中编辑并重试；保存为新请求，原失败记录保留 |
| 未改输入的重生成 | 使用“重新生成”，复用原用户节点 |
| 切换本轮版本 | 使用最新回复旁的版本箭头，同时恢复该版本的用户输入、回复、记忆、变量及工具过程 |

修改后的输入在新结果成功提交前标为“待提交输入”，原已提交版本继续有效；失败、取消或拒绝审核均不部分替换剧情与状态。编辑不会另发修订提醒，也没有“仅保存文字”的操作。

每次重生成都从本轮脚本、Tracker 和模型处理之前的快照开始，按本轮输入与当前授权重跑相应流程。handoff、长期笔记、剧情规划、分类记忆、世界书和变量只采用该起点及本次成功结果，不继承被替换回复的工作。Tracker 周期按相同剧情轮号计算，重试次数不会累计推进窗口或剧情轮数。

修改输入会创建同一位置的新用户节点及新回复，旧输入与旧回复作为整轮版本保留；未改输入则复用原用户节点。修改输入后始终重新开始工具流程，未改输入的 Full Agent 失败回合仍可续接有效进度。编辑发起的重试不附带原回复参考或额外重写要求。

展开“重新生成”可填写补充要求，并选择“带上原 AI 回复作为重写参考”，默认关闭。开启后，完整原回复作为本轮改写素材，故事状态仍从回合前快照开始。参考仅用于此次重写；失败后重试恢复原选择，Full Agent 改变这一选择时重新开始本轮。

选项浮层可再次点击按钮或按 Esc 收起，收起后保留要求与勾选。成功提交新回复后清空补充要求、取消勾选并收起；失败或取消时保留供重试。

失败后仍停留在同一剧情起点时，重生成入口在刷新后继续可用。修改会话设置会按当前版本重新开始；重试使用输入框当前思考强度。切换剧情位置或已有更新回合后，入口跟随当前进度。

回合错误仅在实际请求失败时弹出一次通知。重新进入对话或展开工作记录不会重复通知；失败状态在输入框上方保留，具体错误可在对应回合的工作记录中查看。

## 创建独立分支

从选定 AI 回复创建分支，会复制该回复及祖先消息和快照，继承运行模式、渠道及会话设置，并重映射记忆来源与世界书锚点。新分支作为独立会话保存，源会话可单独管理。

书架角色卡是新故事的模板，已有故事使用独立资料。当前故事的设定从对话内编辑，或按本轮授权维护；角色卡操作见[编辑指南](card-author.md)。

## 世界书与文字显示

中途世界书条目可在注入列表中移除，作用范围与冷却规则见[移除说明](lore-removal.md)。

正文、编辑框和发送框将中文单双引号显示为开合方向明显的弯曲字形，存档、复制和模型请求保留原字符。字体实现见[前端资源](../development/structure.md#前端与生成资源)。
