# 阅读、编辑与分支

Half Agent 和 Full Agent 都保存完整剧情，并分别管理模型窗口和页面显示范围。历史阅读用于浏览存档，模型请求按当前上下文设置编排。

## 定位历史

右侧对话刻度栏覆盖当前分支：白色三角表示阅读位置，黄色标记表示计划缓存断点，圆环表示预览位置。点击或拖动可快速定位；长对话先显示全局概览，再展开附近五个位置供精确选择。

悬停、点击或聚焦刻度可查看轮号和正文摘要，滚轮及“上一轮／下一轮”切换预览，点击条目跳转。刻度获得焦点后，方向键逐轮跳转，Home／End 跳到首尾，Enter 确认预览，Esc 关闭。触屏可先点击刻度，再使用预览按钮。

页面按需渲染阅读位置附近的消息，其余历史继续保存在存档中。缓存标记见[提示缓存](prompt-cache.md)，工具过程见 [Full Agent 使用指南](full-agent.md)。

## 编辑与重生成

两种模式都可编辑当前分支最后一轮的用户消息与 AI 回复，待重试输入也可直接修改。编辑框沿用正文排版，Markdown 和 HTML 使用原文编辑。要从更早事件改变故事，先创建分支或切换回复版本。

| 操作 | 方式 |
|---|---|
| 编辑 | 单击编辑按钮，修改后点击“保存修改”或按 Ctrl+Enter，再选择“提醒 AI”或“不提醒 AI” |
| 提前选择提醒方式 | 长按编辑按钮 300ms 或按 Shift+F10，选择方式后进入编辑，本次保存沿用该选择 |
| 放弃编辑 | 按 Esc，或关闭编辑区 |
| 修改待重试输入 | 编辑后直接保存 |

“提醒 AI”在下一次发送或重生成时，将最新修订交给 Writer／Full Agent 及当轮运行的 Tracker。提醒在成功提交后消费，失败、取消、预览或拒绝审核时继续保留。同一消息重复编辑以最新选择为准；“不提醒 AI”撤回该消息尚未发送的提醒。

编辑文字后，记忆来源会重新校验：

| 模式 | 记忆与上下文处理 |
|---|---|
| Half Agent | 保留记忆并标记来源变化；手动重建时按当前可见原文重新核对 |
| Full Agent | 保留交接笔记与长期笔记的来源过时标记；选择“提醒 AI”后旧工具续答退出本地活动窗口，后续可重新查阅笔记 |

提醒选择、来源状态和记忆重建分别管理。变量通过变量界面修订，或从合适的剧情进度重新生成；纯文字编辑保留原变量快照。

重生成复用原用户输入和回合前快照，新回复保存独立状态。切换回复版本时恢复对应状态和工具过程，已完成剧情轮数保持不变。

展开“重新生成”可填写补充要求，并选择“带上原 AI 回复作为重写参考”，默认关闭。开启后，完整原回复作为本轮改写素材，故事状态仍从回合前快照开始。参考仅用于此次重写；失败后重试恢复原选择，Full Agent 改变这一选择时重新开始本轮。

选项浮层可再次点击按钮或按 Esc 收起，收起后保留要求与勾选。成功提交新回复后清空补充要求、取消勾选并收起；失败或取消时保留供重试。

失败后仍停留在同一剧情起点时，重生成入口在刷新后继续可用。修改会话设置会按当前版本重新开始；重试使用输入框当前思考强度。切换剧情位置或已有更新回合后，入口跟随当前进度。

## 创建独立分支

从选定 AI 回复创建分支，会复制该回复及祖先消息和快照，继承运行模式、渠道及会话设置，并重映射记忆来源与世界书锚点。新分支作为独立会话保存，源会话可单独管理。

书架角色卡是新故事的模板，已有故事使用独立资料。当前故事的设定从对话内编辑，或按本轮授权维护；角色卡操作见[编辑指南](card-editor.md)。

## 世界书与文字显示

中途世界书条目可在注入列表中移除，作用范围与冷却规则见[移除说明](lore-removal.md)。

正文、编辑框和发送框将中文单双引号显示为开合方向明显的弯曲字形，存档、复制和模型请求保留原字符。字体实现见[前端资源](../development/structure.md#前端与生成资源)。
