# 世界书库与挂载

世界书库保存不属于任何角色卡的独立世界书，可在多张角色卡之间复用，也可在新建对话时挂载。接口与持久格式见[设置持久化与 API](../reference/settings-api.md#世界书库与挂载)，检索与注入规则见[世界书检索](retrieval.md)。

## 书库

书库接受 SillyTavern World Info JSON 和 V2 `character_book`，`entries` 可以是数组或对象。原 JSON 无损保存，校验规则与嵌入角色卡的世界书相同：条目及其扩展必须是对象，`extensions.terrarium.audience` 只能是 `writer` 或 `tracker_mvu`。书级设置（如 `scan_depth`、`token_budget`）随原文保留，但与角色卡世界书一样不参与运行。导出时四个世界书开关按[角色卡导出规则](compatibility.md)统一字段名。

书库中的世界书是模板。修改或删除只影响之后的挂载与导入，已挂载的对话保留各自的副本。

左侧栏“世界书”页列出书库。“新建”创建空世界书；“导入”读取 JSON 文件，书名取文件中的 `name`，没有时取文件名。点击一本世界书进入编辑页：可修改书名，添加、编辑、筛选和删除条目，条目编辑与角色卡世界书相同。未保存修改保留在当前浏览器标签页中，“恢复原稿状态”放弃这些修改；保存时如果书库中的版本已被其他页面修改，保存失败并保留草稿。“导出世界书”下载已保存的版本。删除前会在列表旁确认。

制卡 agent 可以引用书库中的世界书并在审阅后保存回书库，见[引用世界书库中的世界书](card-author.md#引用世界书库中的世界书)。

角色卡编辑页可通过“导入世界书 → 从世界书库导入…”把一本书的条目一次性复制进角色卡草稿，规则见[编辑角色卡](card-author.md#手工编辑与复制)。

## 挂载到对话

新建故事的第 3 步“挂载世界书”可以勾选书库中的世界书；书库为空时可直接进入故事。已有对话在“场景 → 编辑对话世界书 → 挂载世界书”中调整：已挂载的书显示本对话中的条目数和状态（与挂载时一致、书库已更新、书库中已删除），取消勾选即卸载，“重新载入书库最新内容”换成书库的当前版本；书库中的其他世界书可勾选挂载。编辑页有未保存修改时需先保存或恢复原稿状态。对话世界书中的挂载条目标注“来自「书名」”。

挂载会把书库条目复制进对话级角色卡的世界书。副本与角色卡自带条目一视同仁：参与检索和常驻注入，可被 Tracker、Full Agent 工具和参谋 agent 读取，也会被 MVU 初始化与角色脚本看到。每个副本获得新的条目 ID，避免与角色卡条目或日后从书架卡同步的条目重号。

对话记录每本挂载书的名称、挂载时的修订号和它带来的条目。这份记录保存在剧情快照中，不写入卡片文档，也不进入模型输入。书架卡同步不比较挂载条目，选择全部覆盖时也保留它们。

对话中调整挂载与手工编辑对话世界书相同，作为一轮设定修改提交：

- 对话必须空闲；更新策略为审核时，修改进入审核。
- 调整生成最新回复的新版本；切换回旧版本或分支时，挂载状态随之恢复。
- 卸载会移除这本书在对话中的全部副本，包括对话中对这些条目的修改。
- 重新载入先卸载，再按挂载顺序复制书库的最新内容；书库修改不会自动进入已有对话。
- 卸载或重新载入后条目 ID 重新分配，冷却等使用状态从头开始。

### 需要注意的行为

- 调整挂载会改变世界书内容：Half Agent 重建请求前缀，Full Agent 开始新的上下文周期，这一轮的提示缓存不会命中。
- 中途挂载含 `[InitVar]` 的世界书时，下次运行时打开会补充初始化新的顶层变量，已有变量不被覆盖；开场已使用 `<initvar>` 时不生效。卸载不会删除变量。用途为 `tracker_mvu` 的条目会成为 Tracker 的变量规则。
- Half Agent 已冻结在窗口中的中途注入，卸载后仍保留到随剧情自然退出窗口，与删除条目的现有规则一致；Full Agent 会立即丢弃对应记录。
- 角色脚本只认一本角色世界书，挂载条目会出现在脚本读取的条目中。整本重写世界书的脚本可能移除挂载条目，此时挂载记录中缺失的条目会被忽略。

## 新建对话默认项

书架角色卡可以预设一个用户角色和若干世界书，作用仅限于新建对话时作为预选项，不影响已有对话，也不写入角色卡文件。在角色卡编辑页点击“新建对话默认项”设置；按钮上的数字是已预选的项目数，悬停显示具体内容。用这张卡开始新故事时，第 2 步预选用户角色，第 3 步预选世界书，并提示“已按角色卡默认项预选”，创建前仍可修改。删除角色卡、用户角色或世界书时，相应默认项自动解除；复制角色卡时一并复制。个人数据包导出角色卡时，只保留同一包中的用户角色和世界书。
