# 上下文生命周期

正文由规则、角色、用户、常驻世界书、记忆、剧情、中途世界书、状态和本轮输入组成。
配方控制顺序、角色、深度、预算和条件；新对话复制全局配方，已有对话和分支独立保存。
每个配方块遵循保存的顺序；深度留空时按列表注入，0 放在末尾，正整数从最后一条剧情消息向前定位。应用系统提示词也可移动；检索协议、当前对话偏好和常驻世界书由运行时补充在顶部，默认跟在应用系统提示词之后。每条实际注入的世界书正文用 `<lorebook>` 与 `</lorebook>` 包裹，包括常驻、中途和按配方位置注入的条目。
角色卡的系统提示、描述、性格、场景、示例对话和历史后提示词分别使用 `<card_system_prompt>`、`<card_description>`、`<card_personality>`、`<card_scenario>`、`<card_mes_example>` 和 `<card_post_history_instructions>` 包裹。运行时系统提示不加标签；开场白及备选开场白作为普通剧情消息发送，在 Writer 和后台整理上下文中均不加标签。新配方把前四个角色卡字段拆成独立块；旧配方的合并角色设定可在编辑器中一键拆分，保留原块的角色、深度、条件等参数。
默认编排将历史正文、锚定本次输入的世界书条目（如有）和本次用户输入连续放置；后置指令、作者注、记忆与当前状态随后注入。固定资料与常驻世界书维持稳定的请求前缀，以提高 prefix cache 命中率。
作者注、记忆、状态和用户输入均可自行调整位置；滚动世界书始终紧贴对应的剧情消息或输入锚点。Half Agent 的尾部动态块保留按时间更新的记录；移动配方块或修改深度会重建上下文，按新的编排发送。
剧情页“预览下次 messages”导出按当前分支与输入只读编译的完整 Writer 消息数组，含适用的后置指令与动态上下文块。只读编译不运行神经召回，实际发送时的世界书命中可能不同。

状态块只提供实际剧情值；开场/世界书初始化账本、MVU schema、重复的 display/delta 缓存及 `$internal` 等元数据不进入请求。宏展开、MVU及记忆参考资料使用相同状态视图，存档原值和执行校验保持完整。源ID、指纹等只留在编译 trace/工作记录，确需模型引用时使用短编号；详见[模型数据边界](model-data-boundary.md)。

## 容量和滚动

日常输入预算默认 98,304 tokens，用于窗口压力估算和按完整交流换出旧历史。已选中的文本块不因此缩短或省略；估算超量时提示并完整发送，服务商仍可能拒绝请求。
本地使用 BPE 分词器估算 tokens，不将估算冒充服务商实际用量。界面分别显示上次实际输入、当前预估和内容占比。

历史消息 cap 只计算剧情消息和本次输入，开场白算一条；中途世界书占用 token 容量，不占消息条数。
五条世界书加用户、assistant 两条消息计两条剧情消息。条目冻结在剧情锚点附近，重复命中不移动位置。
条目与对应交流一起退出后才开始冷却；常驻条目仍受总容量约束。

默认 cap 40、批次目标 10；达到 cap 或日常预算的 85% 时按完整交流边界退出，压力回落目标为 70%。
保护最近两次完整交流及新输入。所有原文留在存档，退出请求不是删除消息。

## 记忆与提交

memory_archive 记录已整理来源，context_window 记录已退出来源，两者不能混用。

整理请求不暴露需机械回填的永久ID与指纹。原文完整拆为带 S 编号的片段（每段最多600字符），模型通过 write_memory 提交增量与片段编号，Runtime 恢复真实来源；历史工具用 H 编号，旧记录用 R 编号，设定用 E 编号。编号映射随基础批次/复核重新生成，只在同一工具续答内复用。新增来源仍必须来自本批，短编号不改变覆盖水位、编辑保留和失败原子性规则。
记忆默认每五轮在正文后整理，可与当轮变量任务合并，与窗口批次独立。退出前强制检查覆盖，不能依赖周期推断安全性。
后台 Tracker 只归档真实剧情和已有记忆，不把召回设定变成已发生事实。
记忆采用有来源的分类增量条目，Runtime 受限提供当时设定及状态作为参考，不把设定当作事件。关键条目来源无效、整体响应无法解析或请求失败时不推进覆盖；仅可选回调条目可单独丢弃。自动整理最多两批加一次可选复核，计数跨窗口重算共享；全部工具续答受该前置/后置 Tracker 任务的模型调用额度约束（默认8）。历史补查另限整次操作3次；Writer仍无工具，补查只作历史依据，不改变覆盖来源规则。详见[一致性记忆](memory-consistency.md)。
丢弃无效记录时显示数量提醒，五秒后自动关闭；详情事件保留在工作记录中，手动整理和自动整理行为一致。

普通发送可以推进窗口；重生成复用用户快照，预览和手动整理不推进窗口。
取消、失败和拒绝审核不提交记忆、窗口或世界书状态。
设定或其他已选文本超出估算容量时给出简短提示，仍完整发送，不静默截断或省略。

检索线索独立保存，不进入模型剧情历史或 MVU。分支重映射锚点，编辑历史使相关来源失效。
只读预览不运行本地神经模型，其不完整性通过诊断明确显示。

Tracker 的独立上下文不消费 Writer 配方或创作提示。后台以本批材料和来源短编号为准，后置任务可以引用当轮待提交正文；最终回调与正文变换后再绑定来源指纹。来源不再支持记录时整轮不提交。
