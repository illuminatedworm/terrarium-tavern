# 文本完整性

已选中的角色资料、世界书正文、剧情和工具结果必须完整进入模型请求。静默截断会让请求继续执行，却失去解释模型行为所需的上下文。

一次性读取完整原文的要求针对角色卡及应用内部数据。角色卡编辑 agent 的外部文件读取允许分页和资源上限；分页结果明确提供范围、`has_more` 和 `next_offset`，不能将片段当作全文。每次返回的片段仍须完整进入模型请求，不得在传输阶段再次截断。网页工具和其他内部读取工具维持原有协议。

## 选择与完整发送

检索可以选择相关条目，窗口可以按完整交流退出旧历史，辅助资料可以启用或关闭。选中以后，不因单块提示阈值或请求估算超量而删除尾部、省略正文或用摘要代替。

估算超量时提示并完整发送，由服务商决定是否接受；拒绝时记录错误，不截短后重试。资料过长需要用户或角色卡作者调整，换窗也不能消除固定资料本身的占用。

用户明确选择官方渠道的云端 compact 后，两种 Agent 模式都允许以服务端加密状态承接已完成交流。本地原文与冻结注入仍保存，维护请求只按完整交流分批；本轮输入及锚定资料不送入历史压缩。Half Agent 的 Tracker 周期记忆继续运行，切回本地时检查退出范围的真实记忆覆盖；Full Agent 使用自己的 handoff 转换，两者不能互换。

[Advisor 参谋 agent](advisor.md)独立保存咨询历史，允许以可查看的咨询摘要或独立云端 compact 承接按完整交流退出的旧咨询。完整咨询和工具原文保留；该机制不替代当前已选的剧情或资料，不写入主故事记忆。

## 内容约束与展示分页

本原则不取消工具参数校验和数据容量约束。handoff、笔记长度、记忆条目数量、活跃记忆容量等校验可以拒绝写入；它们不能通过悄悄截短内容来通过校验。

界面分页或折叠可以限制展示量，工具读取完整正文的协议不因此变化。检索片段只用于召回和来源定位，返回选中条目时仍保留其全文。
