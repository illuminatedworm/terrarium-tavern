# 文本完整性

模型输入按资料来源采用两种读取方式：

| 来源 | 读取与发送方式 |
|---|---|
| 角色卡和项目内部数据 | 按字段、条目或完整记录选择，选中后完整发送 |
| 外部搜索、网页和文件 | 按工具协议返回摘要、片段或分页，并标明来源与限制 |

内部数据包括角色字段、世界书、用户角色、剧情、记忆、变量、笔记、提示词和内部历史记录。工具实际返回的外部片段按原样保存与回放，后续读取通过续读参数取得新片段。

## 选择与完整发送

内部检索按相关性选择条目，窗口按完整交流退出旧历史，辅助资料按设置启停。选中内容在宏展开和模型视图投影后保持完整；预算用于提示、分批和窗口管理。

估算超量时，应用提示后完整发送，由服务商接受或拒绝。固定资料自身过大时，需要调整角色卡、输入或模型容量。

用户选择官方云端 compact 后，已完成交流可通过服务端加密状态承接，本地原文与冻结注入继续保存。整理按完整交流分批，本轮输入与锚定资料保留原文。Half Agent 的 Tracker 周期记忆继续运行，切回本地时检查覆盖；Full Agent 根据完整历史决定是否生成新的交接笔记。

[参谋 agent](advisor.md)独立保存咨询历史，以可查看的咨询摘要或独立云端 compact 承接退出窗口的旧咨询。当前选中的故事资料保持全文，主故事的记忆与规划由各自运行时维护。

## 外部网络与文件资料

外部读取分别限制下载字节、解析资源、处理时间和返回正文量。结果携带来源、摘要／片段／转换文本类型，以及截断、完整性和续读信息。超限或解析失败返回明确错误，并释放连接、临时文件和解析进程。

每次返回的片段与限制信息一同保存，传输层完整发送这份结果。外部内容作为参考，操作权限来自用户授权与运行时工具目录，草稿修改依据来自当前字段的完整读取。

数字参数在 schema 中说明单位、默认值或必填条件、合法范围及端点包含关系。外部文本按从 1 开始的物理行号读取，Office 转换结果及网页按从 0 开始的 Unicode 字符偏移读取；越过末尾的返回方式由对应协议定义。

具体参数见[联网工具协议](../reference/web-tools.md)和[外部文件读取](../reference/card-author-tools.md#外部文件读取)。

## 内部容量约束与展示分页

handoff、笔记长度、记忆条目数和活跃记忆容量在写入时校验，超限返回错误并保留旧内容。界面分页、折叠和日志摘要控制显示范围；内部读取工具继续返回所选记录的全文。
