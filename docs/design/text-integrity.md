# 文本完整性

“读取原文一次返回全文”只针对**角色卡和项目内部数据**，包括选中的角色字段、世界书条目、用户角色、剧情、对话、记忆、变量、笔记、提示词及内部历史记录。它不要求网络搜索、网页或外部文件一次性返回全文。

内部数据按字段、条目或完整记录选择后，必须完整进入模型请求。外部资料可能非常大，采用独立的有界读取协议；外部片段进入聊天记录后，保存和回放的仍是该片段，不是尚未读取的外部全文。

## 选择与完整发送

内部检索可以选择相关条目，窗口可以按完整交流退出旧历史，内部辅助资料可以启用或关闭。选中以后，不因单块提示阈值或请求估算超量而删除尾部、分页回读、省略正文或用摘要代替。

估算超量时提示并完整发送，由服务商决定是否接受；拒绝时记录错误，不截短后重试。资料过长需要用户或角色卡作者调整，换窗也不能消除固定资料本身的占用。

用户明确选择官方渠道的云端 compact 后，两种 Agent 模式都允许以服务端加密状态承接已完成交流。本地原文与冻结注入仍保存，维护请求只按完整交流分批；本轮输入及锚定资料不送入历史压缩。Half Agent 的 Tracker 周期记忆继续运行，切回本地时检查退出范围的真实记忆覆盖；Full Agent 使用自己的 handoff 转换，两者不能互换。

[Advisor 参谋 agent](advisor.md)独立保存咨询历史，允许以可查看的咨询摘要或独立云端 compact 承接按完整交流退出的旧咨询。完整咨询和工具原文保留；该机制不替代当前已选的剧情或资料，不写入主故事记忆。

## 外部网络与文件资料

网络搜索、网页提取和外部文件读取可以限制结果数量，返回摘要、选定片段或分页，也可以在超限时拒绝。需要分别控制下载字节、解析／解压资源、处理时间和返回正文大小；文件或 HTTP 响应体积上限不等于模型输入量上限。

结果应携带来源、摘要／片段／转换文本等类型，以及已知的截断或不完整状态。能续读时提供定位和续读位置；不能续读、无法确认完整性或受服务限制时如实说明，不能把片段称为全文。外部资料不能授予操作权限或替代当前草稿字段的读取证据。

所有工具的数字参数必须明确单位、默认值（或必填）、合法上下界和包含关系；偏移及编号明确从 0 还是 1 开始。动态上界须说明对应的数量，无固定上界时说明越过末尾如何处理。Schema、描述和实际校验应一致。例如外部文本行号从 1 开始，转换后 Markdown 字符偏移从 0 开始，两者不能混用。这一要求同时适用于内部数据工具。

片段与限制信息在工具返回时一起确定。每次实际返回的结果仍完整保存并送往模型，传输层不再偷偷截断；后续可以沿用完整交流退出或用户选择的 compact。具体参数与限制见[联网工具协议](../reference/web-tools.md)及[外部文件读取](../reference/card-editor-tools.md#外部文件读取)。

## 内部容量约束与展示分页

本原则不取消工具参数校验和数据容量约束。handoff、笔记长度、记忆条目数量、活跃记忆容量等校验可以拒绝写入；它们不能通过悄悄截短内容来通过校验。

界面分页或折叠可以限制展示量，内部工具读取完整正文的协议不因此变化。内部检索片段只用于召回和来源定位，返回选中条目时仍保留其全文。外部资料的分页由各自工具协议决定。
