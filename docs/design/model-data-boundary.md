# 模型输入的数据边界

这是强制工程约束：模型负责理解剧情、判断变化、选择依据及编辑语义内容；程序负责身份定位、版本、指纹、逐字摘录、机械转换与提交。长随机ID、哈希和无关运行账本不得成为模型需要阅读、复制或回写的业务数据。

## 各请求路线

Full Agent 见 [消息与数据边界](full-agent.md#消息与数据边界)：长期笔记与状态按需读取，checkpoint 随窗口携带。UUID/指纹、检索诊断仍不要求模型阅读或回写。

| 路线 | 模型需要的内容 | 留在 Runtime 的内容 |
|---|---|---|
| Writer / 脚本嵌套生成 | 角色、已准入设定、自然语言记忆、剧情、实际状态值 | 消息ID、世界书身份、检索诊断、初始化账本、MVU schema 与重复展示/变化缓存 |
| Tracker 周期 / 裁剪前 / 手动重建 / 复核 | 原文片段 S/H、旧记录 R、参考资料 E，以及简明内容字段 | 原文消息ID、指纹、完整设定身份和版本、新记录永久ID；由程序恢复 |
| Tracker 授权维护 | 世界书搜索全文及 L 引用、历史 H 引用、记忆内容、实际状态、可逆角色视图 | 世界书准入/冷却数据、消息和记忆永久ID、来源摘录配对、内部文档哈希 |
| MVU 分析 | 实际 `stat_data`、变量规则正文、近期历史、本轮对话 | 规则条目ID及版本哈希、`$internal` 等元数据；规则来源仍在本地工作记录中 |
| Card Editor | 文档内容、短路径、@D 引用、简明校验结果 | 长身份、指纹及哈希；应用补丁时由程序恢复、保留或生成 |
| 旧记忆对照路线 | 原有完整摘要语义，原文改为 S 片段引用 | 真实消息ID及逐字摘录，由程序回填；不为对照保留已禁止的机械负担 |
| Embedding / Reranker | 正文、标题、关键词、检索查询 | 条目ID、索引键及版本哈希只用于本地关联，不进入模型的文本序列 |
| 模型连接测试 | 探测文字及返回要求 | 不提供会话、角色、消息或缓存身份 |

原始存档、快照、日志、资源文件及前端编辑 API 继续使用真实身份和完整数据。它们不是模型输入。底层原生函数调用的关联标识仍由传输适配器管理，不属于要求模型抄写的业务字段。

## 实际状态与内部账本

`model_view.state_for_model` 只生成请求视图，不修改状态：根部的 `initialized_openings`、`initialized_lorebooks`、`schema`、`display_data`、`delta_data` 留在运行时；递归排除 `$internal`、`$meta`、`$arrayMeta` 和MVU 扩展占位值。实际剧情变量和平铺状态仍保留。

此规则用于 Writer 编译、模型文本的宏展开、Tracker 状态读取、MVU 输入和记忆辅助资料。它防止初始化材料、开场UUID与重复缓存再次混入正文请求，也降低输入占用。约束和变量校验仍由原来的 MVU/Runtime 实施，并未删除存档中的 schema 或初始化标记。

## 工具中的短引用与可逆编辑

授权维护的 `search_lore` 返回 L 编号、名称和完整条目正文，并将启用的命中条目选择交给原上下文准入流程；不再提供额外的世界书读取工具。搜索不返回整条配置。历史查询只返回 H 片段；`write_memory(content, source_ref, kind)` 选择 H 引用，程序填写消息来源及摘录，不返回新记忆的永久ID。历史搜索、读取共用的3次额度与维护的4次模型请求上限保持原样。

Card Editor 与授权角色资料读取使用 `ModelView`。结构化长身份、不透明键、源代码中的UUID/长十六进制标记转为本次操作内的 @D 短编号；`fingerprint`、`checksum`、`sha256` 和 `_hash` 字段不展示。完整映射仅存在 Runtime 内存中，不交给模型、不写回文档。源代码中的标记在应用编辑前精确恢复，不采用模糊匹配。

JSON Pointer 的路径逐段解码、还原及转义，确保包含 `/` 或 `~` 的键仍是一个键。替换父对象时保留其被隐藏字段；数组重排按身份保留元数据，插入新项不能继承下一项的ID。新增世界书条目可以省略ID，由程序生成。直接改动隐藏哈希、引用未知短编号时拒绝本次工具修改；修改仍在原草稿中原子提交。

字段读取先投影再分页，防止长ID被分成两段后漏出。工具续答、校验错误、搜索结果也使用同一视图。默认适配不读取或修改开场；用户明确要求迁移开场时使用 `set_opening`，由程序管理身份与指纹。内置适配 skill 不向模型提供哈希结构或要求模型生成条目ID。

## 成本与验证边界

优先删除无用字段，确需引用才提供短编号。此改动不增加模型请求、工具调用上限或自动重试；不要求换更强模型或增大输出预算。短编号及包装仍计入 tokens，实际费用以服务商用量和计价为准，不能仅凭减少字段就声称具体省钱百分比。

离线测试检查最终业务 messages、工具续答、哈希隐藏、短编号恢复、父对象替换、数组重排/插入、路径转义、持久数据不变及错误拒收。真实模型的语义成功率、费用与延迟需要独立评估；离线回归不提供这些结论。
