# 模型输入的数据边界

模型负责理解剧情、判断变化、选择依据和编辑语义内容；程序负责身份、版本、指纹、摘录、转换与提交。模型业务输入只包含完成任务所需的数据，长期存储和协议身份由运行时管理。

## 请求路线

| 路线 | 模型可见内容 | 运行时保留内容 |
|---|---|---|
| 归档召回筛选（可选） | A 编号的候选内容、人物、故事时间与性质，最近一次交流和当前输入 | 归档记录 ID、来源与指纹 |
| 制卡 agent | 卡片与引用世界书的内容、C 编号、短路径、@D 引用、校验结果、用户角色名称与 P 编号、按需读取的完整角色介绍 | 库中资料的 ID 与修订号、长身份、指纹与精确恢复映射 |
| 剧情模型 | 当前窗口（仅用户消息前有 `[H]` 位置行）、由程序标注覆盖范围的 handoff 章节与当前交接（要点可选 H 引用，C 用于章节操作）、规划和按需工具结果 | 存储身份、来源指纹、检索与事务状态 |
| 运算与掷骰 | 调用参数包含 JS、汇总选择和模型写给玩家的可选备注。工具续答包含程序返回值和默认模式的实际骰点及取舍 | 文件、网络、模型凭据、会话状态、宿主接口和运行环境标识 |
| 剧情看图 | 授权图片的 I 编号、名称及用途；显式调用 `view_image` 后提供原图。配音启用时可见片段和字符额度，生图启用时可见图幅与参考图额度 | 角色音色 ID、模型配对、媒体资源和任务 ID、文件哈希、所属回复版本、图片读取回执与目录引用 |
| 角色配音 | 配音服务接收选定声音、完整台词、协议启用演绎指令时接收用户保存的基础指令与本次演绎要求。语言、采样和音量等选项通过对应协议字段传递 | 故事正文、存储身份、任务队列、凭据与连接映射 |
| 剧情生图 | 模型名、完整画面提示词和已授权参考图原图。支持画质和尺寸的协议另收对应参数；Chat Completions 将提示词和原图放入同一条用户消息 | 故事全文、资源 ID、文件路径、哈希、生成与重试状态、凭据 |
| 参谋 agent | 当前故事参考、咨询记录和按需工具结果。剧情对话单独授权后可按 N1 定位并读取有界参考文件片段 | 来源锚点、版本、参考文件身份与授权修订、咨询进度与偏好提交状态 |
| 资料调查者（用户明确开启） | 委派问题、必要背景、后续补充、已授权的 N1 定位线索和原文片段，或调查指引、搜索摘要和网页片段，以及按固定机制压缩的调查历史 | 文件路径与身份、R 调查者身份映射、消息队列和收件回执、来源版本与模型连接。剧情模型只收报告、提问和简短状态。联网服务接收单次查询参数或目标网址 |
| Embedding／Reranker | 正文、标题、关键词及查询 | 索引身份、向量关联键和版本哈希 |
| 模型连接检查 | 探测文字与返回要求 | 剧情、角色和业务身份 |

原始存档、快照、资源、日志和前端编辑 API 保留完整数据。原生工具调用 ID 用于传输关联，不属于模型需要复制或生成的业务身份。剧情模型的逐类可见性见[数据表](story.md#模型可见数据)。

## 状态投影

[core/model_view.py](../../src/tavern/core/model_view.py) 的 `state_for_model` 生成请求视图，不修改源状态：

- 根部 `initialized_lorebooks`、`schema`、`display_data` 和 `delta_data` 留在运行时。
- 递归排除 `$internal`、`$meta`、`$arrayMeta` 和 MVU 扩展占位值。
- 实际剧情变量和平铺状态保留。

剧情模型的状态读取、模型文本宏和 MVU 输入共用此视图。MVU 校验仍访问完整 schema 和初始化记录。

## 来源短编号

- **H** 是当前分支的消息位置（开场白为 H1），剧情模型、参谋 agent 与剧情界面共用 [history_refs.py](../../src/tavern/core/history_refs.py) 的定义。`H41-H50` 表示连续闭区间，`H52#3` 表示 H52 的第 3 个原文片段。H 只是渲染形式，存档仍保存消息 ID、指纹与逐字摘录。

剧情模型的 `recall_lore` 返回每项的 L 编号及开头；短条目直接返回全文。`read_lore_full` 按一个或多个在场编号读取冻结全文，详见 [工具参考](../reference/story-tools.md)。

短编号的生成、映射回源和来源校验均在本地执行。各运行时管理任务请求额度。编号和包装仍计入输入 tokens。

媒体的 I 编号仅供选择图片，TTS 没有台词编号，直接接收业务文本且不做正文匹配或来源校验。目录和看图回执保存稳定引用，分支复制保留其意义；原图在真正发送请求前加载，编码不当作文字 tokens。媒体凭据沿用现有提供商管理，不进入剧情模型、工具结果或媒体任务参数。

## 可逆角色视图

制卡 agent 与剧情模型的授权角色编辑使用 `ModelView`：结构化长身份、不透明键及源代码内的 UUID／长十六进制标记转为 @D 编号；`fingerprint`、`checksum`、`sha256` 和 `_hash` 等字段隐藏。完整映射不交给模型，也不写回卡片。

制卡 agent 用 N 引用定位可移动文档，目录比较依据只保存在程序侧。打包指引中的字段名和工具名保持原义。制卡 agent 将映射与完成的请求记录一起保存在编辑上下文中，使跨轮原生回复中的编号保持含义；模型/配置重建时保留可恢复的映射；新输入字面编号冲突时重新分配并从原文建立基线。

| 编辑情况 | 恢复规则 |
|---|---|
| JSON Pointer 路径含 `/` 或 `~` | 逐段解码、恢复和转义，保持原键边界 |
| 替换父对象 | 保留被投影隐藏的字段 |
| 数组重排 | 按身份保留对应元数据 |
| 数组插入 | 新项不继承相邻旧项的身份 |
| 新增世界书条目 | 可省略 ID，由程序生成 |
| 未知 @D 或修改隐藏哈希 | 拒绝本次工具修改 |
| 源代码中的身份标记 | 在应用编辑前精确恢复，不模糊匹配 |

资料先完成身份投影，再生成搜索摘要或工具结果；完整读取仍返回全文。搜索、续答和校验错误使用同一视图。开场可按文档引用局部替换，`set_opening` 可增删、排序或编辑完整原文，适配范围见[世界书用途与初始化](../guides/card-author.md#世界书用途与初始化)。

制卡 agent 在调用网页服务前恢复 `web_search` 的 `query`、`objective` 和 `read_webpage` 的 `url`，返回结果继续使用同一视图投影。恢复限定在这两个网页工具的服务调用入口，不对全部工具参数统一展开。

## 验证边界

[test_model_data_boundary.py](../../tests/backend/test_model_data_boundary.py)及编辑专项检查最终业务 messages、工具结果、字段隐藏、编号恢复、父对象替换、数组操作和路径转义。检查覆盖最终模型可见数据与持久化结果。

程序能校验引用存在、权限和数据结构，无法仅凭合法编号证明模型理解正确。语义质量与实际输入成本需要另行评估，见[验证说明](../development/validation.md#检索与模型质量评估)。
