# 统一提示缓存

正文模型默认由本地运行时选择缓存边界；后台维护与角色编辑默认交给云端。用户可在模型高级设置切换“云端默认 / 本地运行时控制”。云端模式不注入缓存字段，也不代表关闭服务商自己的缓存。

## 边界与预览

Full/Half Agent 共用当前分支的断点解析器，默认每新增一轮正文跟进一次，选择倒数第三个已完成的 assistant 正文回复。右侧“缓存”页可按会话调整跟进间隔 N 与倒数位置 K，或切换手动固定；仅本地运行时控制时显示。悬停已完成 AI 正文回复末尾会显示黄点，点击固定整条回复末尾，开场白和工具交换不能被选择。

跟进策略及进度保存在 `sessions.cache_breakpoint_follow`，包括 `interval`、`offset`、`anchor`、`progress`。修改自动策略或恢复自动立即定位并归零计数；之后只在新增正文成功提交的同一事务内推进。重生成、维护、失败和取消不计轮次，重复提交不会重复推进。`PUT /api/sessions/{sid}/cache-breakpoint` 可选传入正整数 `follow_interval`、`reply_offset`，省略时保留已有值，继续使用 `expected_revision` 防止覆盖并发修改。

分支继承策略，自动模式在新分支重新定位、归零计数；手动位置映射可继承的消息 ID，失效选择保留并明确提示。目标不在当前窗口时回退到常驻世界书、角色资料、固定前缀，不更换为另一条正文。新增数据库字段按默认 1、3 迁移，保留现有手动位置。

上下文预览保存计划断点和来源；传输时才把内部标记转换为服务商参数。工作记录保存最终请求、实际 URL、缓存状态、工具定义与前缀摘要。UI 中“已发送”仅表示参数已发出，不表示服务商认可断点或命中缓存。

## 历史导航与渲染

对话右侧刻度栏按回合提供纯文本预览、点击／拖动跳转和方向键、Home、End 定位；白色表示阅读位置，黄色表示计划断点。引用原文、定位缓存与历史导航使用同一个消息定位入口，不再需要展开 60 条历史。导航覆盖当前分支完整历史，UI 渲染范围不影响模型上下文。

不超过 120 条消息且正文合计不超过 20 万字符时直接渲染；超过任一阈值进入动态高度虚拟列表，保留前后各一屏缓冲，同一会话视图只升级不降级。高度索引按实际消息、世界书注入及工具记录测量，定位及单次高度更新使用对数复杂度索引。编辑中的消息保持挂载。Full Agent 工具摘要按进入渲染范围的消息加载并去重。

脚本交互消息进入渲染范围才加载，之后保留实例到退出该会话视图，避免滚动重新运行脚本或丢失界面草稿。离屏减少布局绘制，不暂停脚本；因此交互实例的内存可能随浏览增长。普通正文的 DOM 数量不随历史浏览累计。后端仍一次返回当前分支完整历史，此次不引入服务端分页。

浏览器验收入口：`python -m tests.browser.browser_history_navigation`（两模式、短对话、一万条历史、断点 UI、交互实例保留与移动端）和 `python -m tests.browser.browser_history_rendering`（四种视口、编辑及旧记忆引用）。性能结果、环境信息与截图写入 `.cache/history-navigation/`。

## 协议

| 接口 | 缓存控制 |
|---|---|
| Chat Completions | 按模型预设或自定义内容块标记；Google 兼容扩展可引用已创建的 Gemini 对象 |
| Responses | 受支持模型使用 `prompt_cache_breakpoint` 与 `prompt_cache_options`；不假定可引用 Gemini 对象 |
| Anthropic Messages | 原生 `cache_control` 内容块标记 |
| Gemini GenerateContent | 创建 `cachedContents`，生成时引用 `cachedContent` 并只发送后缀 |

自动匹配依据模型名称和原生协议，不是能力保证。未知模型要求自定义参数，否则明确降级。自定义模式允许指定内容块字段名、JSON 值和请求级 JSON 对象，不能覆盖模型、消息、工具、采样等核心字段。参数错误由服务商返回，不通过删改历史规避。

原生接口只把固定前缀作为顶层系统指令；动态预算、checkpoint、世界书及回合要求以运行时上下文保留在对应位置。工具权限、变量更新及换窗仍由本地校验。原生工具交换保留思考块、签名和调用标识，以供后续回传。

连接支持根地址及已有 API 前缀；不重复添加 `/v1`，保留部署路径。模型编辑器展示协议对应的生成地址，工作记录包含实际地址。现有提供商协议不自动切换。

## Gemini 生命周期与失败

缓存内容包含系统规则、断点之前的消息、工具定义及工具选择配置。进程内按凭据指纹、提供商、模型、会话、窗口和前缀内容隔离，默认 TTL 300 秒。同一前缀复用，断点前移或前缀变化时重建；每个配置/会话仅保留一个活动对象。旧对象尽力删除，失败及进程退出后由 TTL 回收。句柄不写入故事快照。

前缀不足估算门槛、对象创建失败或接口不存在时，完整发送上下文并显示降级。对象失效或服务商明确拒绝缓存字段时，仅允许一次完整请求重发；超时、断流、普通参数错误和服务端错误不自动重发生成。确定的不支持结果按配置指纹记忆，配置变化、重新检查连接或应用重启后可重新探测。

提供商必须开放缓存创建和引用接口，仅支持 Gemini 生成并不足够。服务商可能接受却忽略内容块标记，因此不可只依据 HTTP 200 宣称缓存可控。

Gemini 不能把固定系统指令拆成缓存部分和生成请求中的补充部分。若所选断点位于固定系统前缀内部，运行时完整发送并提示将断点固定到更后的正文消息，不擅自扩大缓存范围。

## 迁移与计数

旧设置首次迁移前保存 SQLite 备份。现有 Full Agent、Half Agent 正文配置切换本地控制，保留手动断点、提供商和模型；旧缓存键及保留时长转存附加请求参数。迁移递增对应设置版本，后台配置保持云端模式。

应用保存原始 usage，缺失计数使用未知值而非假零。Claude 输入总数包含未缓存输入、缓存读取和创建；Gemini 区分候选输出与思考量；兼容接口识别缓存写入别名。框架内部需要数字累计时采用单独数值视图，不覆盖应用记录中的未知值。

主要验证包括四协议最终 HTTP 请求、Full/Half 分支边界、流终止、工具签名回放、Gemini 对象失效降级、设置迁移备份和浏览器 JSON 编辑。真实服务商验收仅使用短输出合成样本，日志写入被忽略的 `.cache/`。
