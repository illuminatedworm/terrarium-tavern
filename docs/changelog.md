## v0.8.5 — 2026-10-27

### 桌面与 Android 安装包

- 提供 Windows x64 基础便携包，内含独立 Python、锁定依赖与界面，解压后双击 `点击开始.cmd`。桌面窗口与后台脚本复用系统 Edge/Chrome 稳定版，不再捆绑 Chromium；普通浏览器仍为默认入口，默认端口改为 51273。
- 桌面日文词典改为按需下载或离线导入，设置中可查看进度、取消和重试；中英文检索不需要词典。精简便携依赖中的开发资源并保留运行模块、词典和许可；本地向量与重排模型串行预热，避免并发加载留下无效参数。
- 提供 Android ARM64 debug 签名 APK，显示版本为 0.8.5、内部序号为 6。压缩手机顶栏和正文留白，右侧栏使用全宽；MVU 状态栏首次打开后保持挂载，避免收起或切换页面时重建状态。

### 剧情与模型请求

- 新故事可在首次模型任务被后端接收前编辑开场白；保存会重新初始化开场变量和脚本状态。首次任务开始后永久锁定，失败、取消、分支与恢复不会解锁；旧对话保持只读。
- Full Agent 上一轮失败或中断后发送新发言，会先沿用原输入续接并提交上一轮，再发送输入框中的新发言；需要审核时等待接受后继续。续接失败、停止、拒绝审核或切换对话会取消自动接发，新发言保留在输入框；刷新页面后需重新发送。Half Agent 保持原发送方式。
- 统一按模型原生结束信号判断制卡 agent 和参谋 agent 完成，保留完整工具响应和各段答复；云端失败优先展示关键原文。修复请求前缀、思考计数和缓存命中率，模型列表缓存按供应商全局共享。
- 恢复 Full Agent 笔记与剧情规划基于当前版本积累修订的要求；调整 Kemini 的 Interleaving 成对输出及提示顺序。无脚本、无 MVU 数据的卡片按需建立脚本 realm，后台浏览器启用 Chromium 沙箱。
- 重做新建对话设置布局；生成时阅读正文保持位置，可配置回复完成后的定位行为。角色卡导出使用已保存的角色名称。

### 升级注意

- 本次按指定的 0.8.x 系列编号，包含持久格式、模型协议和用户可见行为变化，升级前须备份。数据库由 schema 13 升至 **14**，设置由 version 12 升至 **13**，个人数据包由 version 5 升至 **6**；旧对话开场白保持锁定，旧数据包中的对话导入后同样只读。回退须恢复升级前备份，不能直接用旧版打开新数据库。
- 设置 version 13 迁移 Kemini 三项格式提示为 Interleaving 成对输出，保留其他内容；已有自定义指引请在设置中审阅。请求编排与前缀有所调整，首次调用可能重新建立缓存。
- 源码安装需重新运行 `setup.ps1` 或 `setup.sh`。便携包应解压到新的可写目录，再选择原数据目录或恢复备份；系统需安装完整 Edge 或 Chrome 稳定版，仅有 WebView2 Runtime 不够。基础包不含 CUDA 检索依赖与模型权重；日文词典首次使用需联网下载，离线使用请提前导入，剧情备份不包含该词典。
- Android 要求 Android 9+、ARM64、4 KiB 内存页；仍不支持 16 KiB 内存页设备。APK 沿用本机 debug 签名，覆盖升级需签名一致；安装前先导出个人备份，GPU/NPU 仍需 Android 14+。本次未提供 Linux 二进制包。

## v0.8.0 — 2026-10-24

### Android 本地应用

- 新增内嵌 Python 后端的 Android 应用，故事脚本、制卡工具和 Office 读取分别在独立进程运行。支持系统文件导入与保存、全面屏、系统栏和键盘适配；应用更新后首次启动刷新页面资源。
- 重做启动与失败页面，增加重试入口，应用图标改为三叶草；完善窄屏阅读、长消息定位和开场状态面板显示。
- 本地向量与重排使用单独导入的固定 Qwen3 0.6B Q8_0 GGUF，可分别选择 CPU、OpenCL GPU 或实验性 Hexagon NPU。导入支持进度与取消，界面显示设备探测结果；加速失败明确报错，不自动回退 CPU，模型权重不打入 APK。
- Android 工具链、依赖、模型与构建产物统一放入长期保留的 `android-dev/`，提供从零准备、增量构建和独立开发版真机自检流程。支持范围与构建方式见[Android 开发说明](development/android.md)。

### 世界书与角色卡

- 新增独立的[世界书库](guides/worldbooks.md)，支持导入、编辑、导出和制卡 agent 引用。新故事可挂载世界书，已有故事可挂载、卸载或重新载入对话内副本。
- 书架角色卡可设置新故事使用的用户角色与世界书默认项；角色卡页增加从空白卡开始编辑的入口。世界书与脚本可选字段统一处理空值，编辑器显示字段的生效来源。

### 回合、记忆与上下文

- 两种模式统一按分支位置使用 H 消息编号，Tracker 通过消息与片段编号维护记忆来源；界面显示编号，Writer 正文请求不自动添加历史编号。新增归档经历召回，Full Agent 支持只读章节交接及复用已有交接换窗。
- 修改最新用户输入统一为[整轮重试](guides/story-history.md#编辑与重生成)，从本轮脚本、Tracker 和模型处理前的快照重新开始。旧输入与回复保留为整轮版本，切换时一并恢复记忆、变量和工具过程；设定编辑与卡片交互生成的回复版本也保留对应的记忆覆盖、来源和工具轨迹。
- Full Agent 改用普通文本一次输出完整正文，正文前后均可调用工具，按模型原生协议结束。第二次正文、无正文结束或缺少本轮必要工作时停止并保留进度，不自动追加模型请求；脚本收尾失败后继续只重试本地处理。
- Full Agent 工具协议与 Tracker 操作契约改为分节的 Markdown 引导，工具描述先说明用途，换窗以 Runtime 的上下文预警为准。增加可见的 Full Agent 总运行时限，并修复主动召回与自动注入的排除、冷却状态不一致。

### 性能与稳定性

- 修复宏展开反复深拷贝整张角色卡造成的停顿；桌面向量与重排共用 CUDA 子进程，减少显存占用。两种模式增加可见的单条向量索引时限，Android 完善模型导入锁、设备探测和进程回收。
- 回合失败仅在实际请求失败时通知一次，进入对话或展开工作记录不再重复弹出；修复 Full Agent 上下文预览空白、流式空尾帧和资源处理的一致性问题。
- 完善卡片资源与脚本隔离。Windows/Linux 默认仍使用普通浏览器，可显式选择受控桌面窗口；Android 的认证、主 WebView 网络策略和文件访问策略保持在平台边界内。

### 升级注意

- Windows/Linux 需要停止旧服务并重新运行 `setup.ps1` 或 `setup.sh`，以安装 Python 3.13、锁定依赖和新的前端资源。使用本地检索时保留 `-LocalRetrieval` 或 `--local-retrieval`；已有数据目录中的模型权重无需因 Python 升级重新下载。
- 当前数据库为 **schema 13**、设置文档为 **version 12**、个人数据包为 **version 5**；Full Agent 恢复进度保存普通正文和模型原生结束状态，旧版交付进度可续接，已保存轨迹保留。
- **schema 1–8 中含有剧情的数据（包括 v0.7.0 的剧情）不能直接升级。** 程序会在写入前拒绝。继续旧剧情须保留兼容旧版和原数据；也可使用旧版导出非对话资料到新数据目录。清理脚本会删除全部剧情，仅在明确接受这一结果时使用。详见[升级与回退](guides/maintenance.md#备份升级与回退)。
- 无剧情的旧数据库及受支持的 schema 9–12 升级前会备份；设置 version 12 保留已有设备与自定义配置，旧版个人数据包只导入非对话资料。回退时恢复升级前备份，不能让旧程序打开已升级数据库。
- 提示词、历史编号、交接与回合流程已有调整；已保存的自定义提示词保持原文，需要采用新的默认指引时在界面审阅并恢复默认。升级后的首次请求可能重新建立上下文缓存。
- Android 提供私人安装用的 debug 签名 APK，要求 **Android 9+、ARM64、4 KiB 内存页**，目前不支持 16 KiB 内存页设备。同签名可覆盖安装，安装前先导出个人备份；权重需单独导入，GPU/NPU 另需 Android 14+，并受芯片与驱动限制。

## 升级与版本规则

升级前备份完整数据目录，安装新版依赖和前端资源。数据库 schema、设置文档版本与应用版本是不同概念；旧程序回退应恢复对应版本的备份，不直接打开已升级数据库。具体步骤见[备份、升级与回退](guides/maintenance.md#备份升级与回退)。

后续 `0.8.x` 用于无需额外升级注意的修复和小幅完善，下一轮新能力、持久格式或核心行为调整使用 `0.9.0`。版本号不表示固定完成百分比；在核心行为与升级兼容约定稳定、完成发行验证后再进入 `1.0.0`。
